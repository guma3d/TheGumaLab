# GumaDdanjit 작업 지침

- 2026-10-17 사용자 재확정: Story 롱폼은 Gemini Flash TTS / Zephyr만 사용하고 로컬 TTS를 사용하지 않는다. 자연스러운 내레이션을 먼저 생성한 뒤 실제 발화에 영상과 자막을 맞춘다. 영상 컷별 생성 대신 문맥이 이어지는 단락 묶음을 같은 말투로 생성·보관하고 정상 묶음은 재사용한다. 속도·피치를 영상 길이에 맞춰 변경하지 않는다. 한도/실패 시 로컬·Lite로 자동 대체하지 않는다. 실행 기준은 GumaTTS/story-voice-policy.json이다. 쇼핑·이야기쇼츠·X의 Sohee 정책은 변경하지 않는다.

- 2026-10-17 음성 테스트는 백그라운드 무음 검사로 진행한다. 사용자의 명시적 재생 요청 없이 스피커 재생·브라우저 재생·자동재생을 하지 않는다. 실제 청취와 자동 검사는 구분한다.

- 2026-10-17 Story 롱폼 제외 톤 승인: Sohee + sohee-upbeat-v1 고정. 정확한 영문 말투 지시·seed=43·모델 revision·승인 샘플 작업/해시는 GumaTTS/voice-policy.json이 기준이다. 승인 샘플 51af3c5b9e9e491dbcca532dd3b75693의 문장 끝까지 밝고 신나는 톤을 유지한다. 차분한 기본 톤으로 되돌리거나 컷마다 다른 감정 지시를 넣지 않는다. 샘플 승인은 전체 재생성본의 청취·업로드 승인과 구분한다.
- 2026-10-17 사용자 확정: Story 롱폼을 제외한 신규 내레이션은 한국어 기본 화자 Sohee, Qwen3-TTS 1.7B CustomVoice(qwen-1.7b), language=Korean으로 고정한다. F4 VoiceDesign/복제 및 Zephyr 등 다른 화자로 자동 대체하지 않는다. 쇼핑쇼츠는 전체 대사를 한 번에 생성하고 최종 음성은 분할 재접합 없는 연속 마스터로 사용한다. 피치·배속 변경 없이 발화 경계에 영상·자막을 맞춘다. 사용자가 승인한 밝고 신나는 sohee-upbeat-v1 말투(미소·가벼운 발성·끝음절까지 밝은 에너지)를 그대로 사용하고 모델·화자·한국어 설정·작업 ID·원본·마스터 해시를 보존한다. 모든 컷의 발음·무음·잘림·음량·BGM 대비·로고를 검사하되 실제 청취와 자동 검사를 구분한다. 기존 결과와 과거 승인은 보존하며 이번 샥즈 영상만 새 버전으로 교체한다. 음성 정책은 업로드·공개 승인이 아니다.
- 2026-10-12 쇼츠 썸네일 긴급 기준: 앞으로 제작하는 모든 쇼츠(GumaShop·파생 이야기쇼츠·GumaX)의 핵심 문구는 중앙 크롭 안전 영역에 둔다. [텍스트 잘림 방지](docs/shorts-thumbnail-safety.md)의 다중 비율 크롭·모바일 크기 가독성 검수를 적용하고 잘린 결과는 검수 완료로 처리하지 않는다. 게시 요청 시 실제 YouTube 적용/표시도 확인한다.

작업 시작 시 [통합 지침 안내](docs/guide-index.md), 대상 모듈 AGENTS·상세 기준·최신 작품 인계를 반드시 읽는다. Main도 Story/X 규칙을 생략하지 않는다. 새 피드백은 범위를 기록해 관련 MD·실행 규칙을 갱신하고 폐기 규칙을 제거하되 과거 이력은 보존한다.

- 2026-10-12 웹 운영: GumaShop·GumaStory·GumaX는 공통 디자인의 읽기 전용 제작 보관함을 사용한다. 메뉴는 리소스·이미지 콘셉트·완성 영상 세 가지로 통일하며 프로젝트·최신/전체 버전 검색과 원본 다운로드를 제공한다. 대본·출처·참조 음성은 리소스로 보관한다. 웹 피드백·수정 요청·제작/공개 승인 UI는 제공하지 않는다. 피드백과 정확한 버전의 승인·제작 요청은 Codex 대화로 받는다. 기존 원본·DB·이전 버전·검수/승인 이력을 삭제하거나 재작성하지 않는다.

- 항상 한국어로 답한다. 상위 HomeServer Git·배포·비밀값 보호 지침을 따른다.
- 영상 제작의 운영 서비스는 GumaDdanjit 하나다. GumaShop=쇼핑 쇼츠(app, /shorts), GumaStory=출퇴근 이야기·롱폼(story, /story), GumaX=실험적인 고퀄 영상(shop, /shop)이다. 표시명과 기존 내부 경로를 혼동하지 않는다. 모듈별 AGENTS와 docs/shorts-production.md의 제작 기준을 유지한다.
- 운영 URL은 https://home.guma3d.com/gumaddanjit/ 이다. 단일 컨테이너 GumaDdanjit_app, 포트 8089, 단일 인증 경계와 공통 제작 보관함을 사용한다.
- 원본·버전·대본·검수·승인 기록은 storage/shorts, storage/story, storage/shop에 보존한다. 모듈 ID 공간과 SQLite 이력을 임의로 합치거나 덮어쓰지 않는다.
- 과거 서비스 폴더는 복구용 보관본이다. 기존 링크는 새 모듈로 연결한다. 공개 상품 모음만 로그인 없이 읽을 수 있으며 제작 원본·API는 SSO로 보호한다.
- 수정·제작 결과는 웹과 프로젝트 드라이브에 버전별로 저장한다. 기존 YouTube 영상 변경·비공개 업로드·공개는 정확한 버전과 별도 사용자 요청이 필요하다.
- 기본 결과 공유는 웹 링크와 짧은 텍스트를 사용한다. 긴 로그·이미지·전체 문서를 대화에 반복하지 않는다.
- 음성 교체 후에는 모든 컷의 TTS 원본→보정 음성→컷 영상→최종 타임라인을 전수 검사한다. 전체 평균 음량만으로 통과시키지 않으며 컷별 음량·무음·잘림과 BGM 대비를 확인한다. 실제 청취 여부는 별도로 기록한다.
- 서비스 종료/이관 전에 기존 작업 대기열·실행 작업을 확인하고 DB 일관 백업 및 파일 SHA256을 검증한다. 원본 볼륨·데이터는 삭제하지 않는다.

- 2026-10-11 카테고리 표시: 앞으로 제작하는 영상의 왼쪽 상단에 해당 공간의 텍스트 일러스트(GumaShop / GumaStory / GumaX)를 넣는다. 화면 안전 여백과 자막·광고 표시·핵심 피사체를 피하고, 작은 크기에서도 읽히도록 검수한다. 사용자가 2026-10-11 세 디자인을 최종 승인했다. 확정 원본은 static/branding/category-v1/{GumaShop,GumaStory,GumaX}.png이며 새로 그리거나 다른 글꼴로 대체하지 않는다. 종횡비를 유지해 크기를 조절하고 영상 전체에 적용한다. 최종 검수에서 카테고리 일치·왼쪽 상단 위치·가독성·잘림·다른 표시와의 겹침을 확인한다. 디자인 승인은 개별 영상의 검수·업로드 승인을 대신하지 않는다. 기존 영상은 이 지침만으로 재렌더링하거나 재업로드하지 않는다.

- 카테고리 로고는 첫 프레임부터 마지막 프레임까지 모든 프레임에 포함한다(2026-10-11 재확인). 컷 전환·페이드·인트로·엔딩에도 누락되지 않도록 전환 합성이 끝난 최종 영상 레이어에 고정 오버레이하고, 전체 프레임 검사를 수행한다.
