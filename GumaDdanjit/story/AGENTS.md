# GumaStory — GumaDdanjit story 모듈

- 2026-10-17 사용자 재확정: Story 롱폼은 Gemini Flash TTS / Zephyr만 사용하고 로컬 TTS를 사용하지 않는다. 자연스러운 내레이션을 먼저 생성한 뒤 실제 발화에 영상과 자막을 맞춘다. 영상 컷별 생성 대신 문맥이 이어지는 단락 묶음을 같은 말투로 생성·보관하고 정상 묶음은 재사용한다. 속도·피치를 영상 길이에 맞춰 변경하지 않는다. 한도/실패 시 로컬·Lite로 자동 대체하지 않는다. 실행 기준은 GumaTTS/story-voice-policy.json이다. 쇼핑·이야기쇼츠·X의 Sohee 정책은 변경하지 않는다.

- 2026-10-17 추가 시각 스타일 지침: 내려받은 사진은 조사·출처용 원본으로 보관하고, 최종 영상에는 승인된 입체 일러스트 스타일로 ImageGen에서 재생산한 이미지를 사용한다. 실제 지리 위치·유물의 주요 형태는 참고 자료를 기준으로 유지한다. 지도는 검증된 지리 데이터와 지명 좌표를 유지하면서 색감·질감을 통일한다. 생성 이미지의 문자·세부를 실제 고문서 증거나 정확한 복원으로 취급하지 않고, 사실 비교는 원문 출처와 검증한 설명 도표로 전달한다. 원본 출처·라이선스·스타일 변환 프롬프트·참조 이미지·결과를 함께 기록한다.

- 2026-10-17 최신 화면 피드백: 캐릭터에만 화면을 한정하지 않는다. 실제 장소·유물·문서 사진을 참고해 같은 스타일로 재생산한 이미지, 검증한 지리 데이터 기반 지도, 도표, 상황 일러스트를 내용에 맞게 섞는다. 사해문서 v2는 기존 14장 대비 3배인 최소 42개의 서로 다른 이미지 리소스를 사용하고 단순 크롭을 새 이미지로 세지 않는다. 기본 숏 3~5초, 최대 7초를 편집 목표로 삼고 긴 설명은 디테일 인서트·분할 비교·지도 이동으로 나눈다. 카메라 움직임, 포인터, 경로, 문서 리빌 등 의미 있는 변화가 이어지게 하되 무의미한 흔들림·번쩍임은 피한다. 설명에 필요한 짧은 텍스트 애니메이션은 허용하며 자막을 반복하는 키워드 팝업은 남발하지 않는다.
- 2026-10-17 자막 최종 정정: 확대율은 50%가 아니라 20%다. 사해문서 v1의 1080p 52px → 62.4px로 적용한다. 자막은 배경 상자 없이 얇은 외곽선의 한 줄로만 표시하며 긴 문장은 짧은 의미 단위로 나누거나 압축한다. 글자 크기를 줄여 맞추거나 두 줄로 자동 줄바꿈하지 않는다. 단어 단위 음성 동기화보다 읽기 쉬운 표시 시간을 우선하되 의미와 수치는 유지한다. 실행 기준은 production-rules.json을 읽는다.
- 2026-10-17 무음 검수: 오디오·영상 검사는 백그라운드 디코딩·ASR·파형·프레임 검사로 수행한다. 사용자가 명시적으로 재생을 요청하기 전에는 스피커 출력, 브라우저 재생 버튼/목차의 play 호출, 자동재생을 실행하지 않는다. 무음 검사를 실제 청취로 기록하지 않는다.

- 2026-10-13 말투 추가 피드백: 낭독 문장의 끝을 ‘~다/~습니다’로 반복하지 않는다. 전체 대본은 친구에게 편안히 이야기하는 구어체로 쓰며 ‘~잖아요/~거든요/~죠/~어때요?’ 등의 어미를 상황에 맞게 섞고 짧은 독백·질문·반응을 사용한다. 어미만 기계적으로 교체하지 말고 문장 구조와 전개도 함께 바꾼다. ‘친구처럼’은 반말 강제나 ‘야/너’ 호칭의 반복이 아니다. 단정적인 보고서 문장·강의식 예고·훈계 결론을 줄인다. 제목과 자료 출처·검수 메타데이터는 구어체 강제 대상이 아니다.

- 2026-10-13 최신 서술 피드백: 사회·기업 문제를 친구와 수다 떨듯 친근하고 재미있게 설명한다. 공감할 생활 장면·기대와 현실의 모순·짧은 관찰과 농담으로 시작하고, 데이터는 그 상황의 규모나 차이를 드러내는 재료로 자연스럽게 연결한다. 조사→원인 목록→균형 잡힌 반론→개인 해결책의 강의식 구성을 기본으로 강제하지 않는다. 시청자에게 체크리스트·자기계발·교훈을 가르치는 결말을 피하고, 기업의 보상·권한·인력·평가 설계와 사회 구조에서 무엇이 바뀌어야 하는지 대화체로 짚는다. 사람이나 세대를 조롱하지 않고 웃음은 제도의 모순에서 만든다. 통계의 문항·대상·연도·분모·인과 한계는 정확히 유지하되 짧고 쉬운 말로 전달하며 상세 출처는 웹에 보존한다. 이 피드백이 과거 강의식 구성 지침보다 우선한다.



필수 연결: [통합 안내](../docs/guide-index.md), [Story 제작 기준](../docs/story-production.md), [발화 검수](../docs/story-prosody-review.md). 최신 seed.json과 대상 작품의 대본/음성/검수/승인 버전을 확인한다.

- 2026-10-12 사용자 승인 편집 시험: 현재 Sohee v2 전체 음성에 확인된 긴 무음의 중간만 줄이고, 발화가 느린 문장만 음높이를 유지하는 속도 보정을 적용한 v3를 만든다. 문장 사이 쉼 약 0.45초·문장 내부 쉼 약 0.22초를 남기며, 속도 보정은 최대 1.12배로 제한한다. 원본·삭제 구간·속도 구간·비선형 시간 매핑·자막 정렬·전후 검수 이력을 보존한다. 원본 v2의 검출 기준을 동결해 수정본을 비교한다. 이 요청은 Sohee 기본 화자 채택이나 다른 영상의 배속 변경 승인으로 확대하지 않는다.

- 2026-10-12 문장 검수 v2: 최종 영상 전체의 컷 음성을 기준으로 실제 낭독 음절당 활동 시간과 쉼 포함 시간, 내부 쉼 비중, 문장·컷 사이 쉼을 각각 검사한다. 알려진 문제 컷 6·10은 기준 계산에서 제외하며 숫자 ASR은 원문 낭독 철자에 대응해 센다. 정렬 미확인은 검토 대상으로 남긴다. 중복 없는 검출 문장/컷 수와 중복 가능한 유형 수를 구분하고, 공유 10개에 맞춰 검출 문턱을 바꾸지 않는다. 후보를 오류나 청취 통과로 단정하지 않는다.

- 2026-10-12 속도 검수: 컷 평균·문장 수만으로 낭독의 자연스러움을 통과시키지 않는다. ASR 어절 정렬과 실제 파형 활동 시간을 함께 사용해 음절당 발화 길이, 컷 내부 속도 차이, 내부 무음을 검토 대상으로 기록한다. 숫자·영문 표기를 한글 음절 수로 잘못 계산하지 않는다. 긴 쉼과 강조는 자동 오류가 아닌 검토 후보이며, 발음 늘어짐 후보와 구분한다. 기준을 문제 컷으로 학습하지 않고 원본·기준·변경 테이크·해시·검수 결과를 보존한다. 미검사/오래된 해시/후보 없음은 자연스러움 통과나 실제 청취 완료를 뜻하지 않는다. 수정은 문제 음성 구간만 현재 채택 모델로 재생성하고 같은 고정 기준으로 재검사한다. Sohee는 과거 비교 시험이며 현재 Gemini Zephyr 채택을 변경하지 않는다.

사용자 확정 표시명은 GumaStory이며 출퇴근 이야기·롱폼 제작 공간이다. 기존 모듈 경로와 저장소 ID는 유지한다.

- 카테고리 로고 확정(2026-10-11): 앞으로 이 공간에서 제작하는 영상은 `static/branding/category-v1/GumaStory.png`(GumaDdanjit 기준)를 왼쪽 상단에 사용한다. 원본 비율과 안전 여백을 유지하고 자막·광고 표시·핵심 피사체와 겹치지 않게 배치한다. 최종 렌더 검수에서 적용 여부와 가독성을 확인한다.

현재 코드·저장소는 GumaDdanjit 아래가 기준이다. 이전 서비스의 컨테이너를 실행하거나 이전 저장소에 새 제작 데이터를 쓰지 않는다. 아래 제작 품질 기준을 통합 환경에서 유지한다.

## 제작 기준

- 2026-10-11 사용자 피드백: Story 영상은 배경음악 없이 내레이션만 사용하는 것을 기본으로 한다. 명시적인 음악 요청이 있는 제작본에만 BGM을 추가한다. ‘가상 장면입니다’ 같은 제작 안내는 대화의 흐름을 끊지 않도록 자연스러운 질문·예시 조건으로 풀며, 진행 번호(01/12)·가상/설명용/편집자 꼬리표 등 제작 안내를 화면에 넣지 않는다. 조사 수치·대상·시점·분모와 예시 조건은 내용에 필요한 만큼 유지하고 상세 출처·제작 이력은 웹에 보존한다.
- 음성은 문맥이 이어지는 단락 묶음 단위로 생성·보관한다. 영상 컷과 생성 단위를 분리하고 원문·설정·작업 ID·해시를 기록한다. 정상 묶음은 재사용하며 변경/실패 묶음만 재생성한다. 원본과 이전 버전은 보존한다.
- 신규 Story 롱폼 음성은 공통 GumaTTS의 gemini-flash / Zephyr를 allow_cloud=true로 명시한다. 파생 이야기쇼츠는 기존 Sohee 정책을 유지한다.
- 한국어로 답한다. 상위 AGENTS.md의 HomeServer 커밋·동기화·배포 원칙을 따른다.
- 서비스는 이야기 영상의 캐릭터 레퍼런스·자료·대본을 관리한다. 쇼핑 제작기와 분리한다.
- 사용자 승인 스타일은 내장 ImageGen으로 만든 《업》 느낌의 입체 캐릭터다. 최신 외형과 기준 ID는 seed.json 및 웹 캐릭터 가이드가 기준이다.
- 성인 남성, 성인 여성, 남자 어린이, 여성 청소년 4개 역할. 성인 여성은 날씬한 현대 여성·안경 없음·스커트 오피스룩. 딸은 고등학생 나이이며 빨간 머리·검은 가죽 재킷·레깅스·액세서리의 비성적인 케이팝 스트리트 패션이다.
- 각 캐릭터의 목표는 기준 정면 포함 각도 6장, 표정 4장, 상황 5장으로 15개 레퍼런스다. 이전 초안과 실패본도 삭제하지 않고 보관 상태로 구분한다.
- 캐릭터 생성은 최신 정면 원본을 참조한다. 수정된 옛 얼굴·의상·나이를 다음 이미지의 기준으로 재사용하지 않는다. 손, 얼굴, 각도, 표정, 의상을 개별 검수한다. 생성 완료를 사용자 승인으로 기록하지 않는다.
- 원본·버전·프롬프트·참조·해시·검토 메모는 storage에 보존한다. 원본을 덮어쓰지 않는다. 대용량 이미지·영상·DB는 Git에서 제외하며 앱 코드·설정·문서만 커밋한다.
- 첫 이야기 주제는 승진, 목표 20분. 초기 시간표는 구성 초안이며 완성 대본·검증된 사실이 아니다. 사실·창작·출처·재사용 권한을 구분한다.
- 대본 저장은 불변 버전을 추가한다. 승인은 대본·이미지·영상·유튜브 업로드 각각 구분한다. 정확한 버전의 명시적 업로드 요청 없이 비공개 업로드도 하지 않는다.
- 대본·시간대별 구성·상세 제작 내용은 GumaStory 웹서비스에 저장하고 공유한다. 채팅에는 전체 본문을 반복하지 않고 버전 고정 링크와 짧은 변경 요약만 남긴다. 기존 버전을 덮어쓰지 않는다.
- 대본에 가상의 인물 이름이나 “민수 씨” 같은 호칭을 붙이지 않는다. 사회 이슈는 짧고 생동감 있는 해설로 풀며, 조사 수치→차트 해석→원인 후보·반론으로 전개한다. 수치의 원문 문항·대상·시점·분모를 확인하고, 실제 조사와 가상 계산·편집자 해석을 구분한다. 해외 수치를 한국 전체에 일반화하거나 오래된 조사를 최신 조사로 소개하지 않는다.
- 홈서버 SSO를 유지한다. 비밀값·인증 쿠키를 출력하거나 커밋하지 않는다. 운영 인증 우회 옵션을 추가하지 않는다.

- 카테고리 로고는 첫 프레임부터 마지막 프레임까지 모든 프레임에 포함한다(2026-10-11 재확인). 컷 전환·페이드·인트로·엔딩에도 누락되지 않도록 전환 합성이 끝난 최종 영상 레이어에 고정 오버레이하고, 전체 프레임 검사를 수행한다.

- 2026-10-11 롱폼 피드백: 레퍼런스는 캐릭터·스타일을 일치시키기 위한 생성 입력이다. 최종 영상의 상황 컷으로 그대로 반복 사용하지 않는다. 대본의 행동·장소·비유에 맞는 이미지를 컷별로 내장 ImageGen에서 새로 생성하고 프롬프트·참조·해시를 보존한다. 자막은 Pretendard 계열의 가벼운 굵기와 얇은 단일 외곽선, 한 줄을 기본으로 한다(2026-10-17 정정). 굵은 Maple 이중 외곽선·팝 확대는 롱폼에 적용하지 않는다. 낭독 원문과 표시 자막을 분리하고 비율·금액·연도·인원·시간은 6%, 400만 원, 2026년처럼 숫자로 표시한다. 원문·기존 음성·과거 버전은 보존한다.

- 2026-10-12 승진 v5 재제작 승인: 최신 대본 v9 낭독 원문을 유지하고 Gemini Flash / Zephyr를 사용한다. 동일 대사 정상 Flash 음성은 재사용하고 변경·검수 후보만 새 테이크로 생성한다. 상황 이미지 카메라 이동, 음성에 맞춘 수치 카운트·막대 확장, Do Hyeon 키워드 등장·교체를 적용한다. 다른 문항의 수치를 증감으로 표시하지 않는다. 자막은 수치·대상·조건을 유지한 의미 요약이며 Pretendard SemiBold 46px→50.6px(+10%), 원문 표현과 ASR 시점에 정렬한다. 이번 사용자의 명시적 요청에 따라 첫 영상의 Carefree BGM 대비 진폭 0.5배(-6.0206dB)의 일정 게인으로 음악을 넣는다. 일반 Story 무음 기본값과 다른 공간 음악 정책은 변경하지 않는다. 원본·테이크·버전·출처·자막·움직임·전 구간 음량/믹스·모든 프레임 로고·검수·웹 공유를 보존하고 실제 청취 여부는 별도로 기록한다.

## 2026-10-17 사용자 참고 영상 적용

참고: 역사본능 [9.11 사건](https://www.youtube.com/watch?v=Xeglv57PZcI), 역사에 반하다 [방주 모양 지형](https://www.youtube.com/watch?v=_qlYehTzfB4). 사실 자료가 아니라 서사와 화면 전달 방식의 참고다. 원문 대사·음성·화면을 재사용하지 않는다.

- 사건·물건·행동으로 시작하고 의외의 전개로 질문을 만든다. 강의식 목차와 같은 설명의 반복을 줄인다. 질문→단서→부분적인 답→다음 질문이 이어지도록 구성한다.
- 말하는 대상이 등장하는 실제 발화 시점에 화면을 맞춘다. 고정 초 단위로 관계없는 이미지를 순환하지 않는다. 전체→세부→비교→맥락의 순서로 시선을 안내한다.
- 숫자·시간·차이는 비례와 관계가 보이는 지도·연대선·비교 도표로 전달한다. 자료의 원문을 AI 생성 문자로 대체하지 않는다. 질문을 자막 위에 다시 띄우는 장식 키워드는 사용하지 않는다.
- 자연스러운 음성을 먼저 만든 뒤 화면을 붙인다. 같은 Zephyr 말투로 문맥 묶음을 생성하며 숫자 검수·대사 일치·묶음 간 속도와 음높이 편차를 검사한다. 무음 자동 분석을 실제 청취나 자연스러움 승인으로 기록하지 않는다.
- 샘플 프레임·ASR 분석 범위를 명시한다. 전체 영상을 보거나 실제로 들었다고 과장하지 않는다. 상세 분석과 작품별 적용표는 버전별 웹 리소스로 보관한다.
