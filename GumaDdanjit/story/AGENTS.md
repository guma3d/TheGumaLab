- 카테고리 로고 확정(2026-10-11): 앞으로 이 공간에서 제작하는 영상은 `static/branding/category-v1/GumaStory.png`(GumaDdanjit 기준)를 왼쪽 상단에 사용한다. 원본 비율과 안전 여백을 유지하고 자막·광고 표시·핵심 피사체와 겹치지 않게 배치한다. 최종 렌더 검수에서 적용 여부와 가독성을 확인한다.

# GumaStory 작업 지침

- 2026-10-11 사용자 재확인: Main 세션에서 선정한 로컬 남성 TTS M5를 사용한다. GumaTTS를 경유하는 Qwen3-TTS 1.7B VoiceDesign이 현재 기준이며 클라우드 음성으로 자동 대체하거나 이미 확정된 모델을 다시 선택하도록 묻지 않는다.
- 음성은 영상 전체를 하나의 작업으로 재생성하지 않고 컷별로 생성·보관·연결한다. 컷 ID, 낭독 원문 해시, 모델·음성 설정, 생성 작업 ID, 음성 해시와 길이를 기록한다. 새 영상 버전에서도 원문과 음성 설정이 같은 정상 컷은 기존 파일을 재사용하고, 수정되거나 검수에 실패한 컷만 새 테이크로 생성한다. 컷 순서가 바뀌어도 번호만으로 기존 음성을 잘못 연결하지 않는다. 변경된 컷의 길이를 반영해 영상·자막 타임라인을 다시 계산하며 원본·이전 테이크와 버전은 보존한다. 자막 글꼴·표시 숫자·화면 안내문구만 바뀌면 음성을 재생성하지 않는다. 기존 클라우드 영상의 로컬 M5 전환은 최초 한 번의 음성 교체이며 이후 편집의 전체 재생성 근거로 삼지 않는다.
- 2026-10-11 사용자 확정: 모든 신규 영상 음성은 GumaTTS의 Qwen3-TTS 1.7B VoiceDesign으로 제작한다. 모든 쇼츠(쇼핑·이야기쇼츠 포함)는 여성 F4(생기 있는 이야기꾼), Story·롱폼은 남성 M5(솔직한 현실 친구)를 사용한다. 롱폼에서 파생한 쇼츠도 F4로 새로 녹음하며 M5 음성을 그대로 재사용하지 않는다. 더 좋은 대안을 사용자가 채택하기 전까지 유지한다. 기존 음성·영상·과거 제작 기록은 보존하고 새 음성은 새 버전으로 저장한다. 모델 선택 승인은 개별 결과물 검수·YouTube 업로드 승인을 대신하지 않는다.
- 한국어로 답한다. 상위 AGENTS.md의 HomeServer 커밋·동기화·배포 원칙을 따른다.
- 서비스는 이야기 영상의 캐릭터 레퍼런스·자료·대본을 관리한다. 쇼핑 제작기와 분리한다.
- 사용자 승인 스타일은 내장 ImageGen으로 만든 《업》 느낌의 입체 캐릭터다. 최신 외형과 기준 ID는 seed.json 및 웹 캐릭터 가이드가 기준이다.
- 성인 남성, 성인 여성, 남자 어린이, 여성 청소년 4개 역할. 성인 여성은 날씬한 현대 여성·안경 없음·스커트 오피스룩. 딸은 고등학생 나이이며 빨간 머리·검은 가죽 재킷·레깅스·액세서리의 비성적인 케이팝 스트리트 패션이다.
- 각 캐릭터의 목표는 기준 정면 포함 각도 6장, 표정 4장, 상황 5장으로 15개 레퍼런스다. 이전 초안과 실패본도 삭제하지 않고 보관 상태로 구분한다.
- 캐릭터 생성은 최신 정면 원본을 참조한다. 수정된 옛 얼굴·의상·나이를 다음 이미지의 기준으로 재사용하지 않는다. 손, 얼굴, 각도, 표정, 의상을 개별 검수한다. 생성 완료를 사용자 승인으로 기록하지 않는다.
- 원본·버전·프롬프트·참조·해시·검토 메모는 storage에 보존한다. 원본을 덮어쓰지 않는다. 대용량 이미지·영상·DB는 Git에서 제외하며 앱 코드·설정·문서만 커밋한다.
- 첫 이야기 주제는 승진, 목표 20분. 초기 시간표는 구성 초안이며 완성 대본·검증된 사실이 아니다. 사실·창작·출처·재사용 권한을 구분한다.
- 대본 저장은 불변 버전을 추가한다. 승인은 대본·이미지·영상·유튜브 업로드 각각 구분한다. 정확한 버전의 명시적 업로드 요청 없이 비공개 업로드도 하지 않는다.
- 대본·시간대별 구성·상세 제작 내용은 GumaStory 웹서비스에 저장하고 공유한다. 채팅에는 전체 본문을 반복하지 않고 버전 고정 링크와 짧은 변경 요약만 남긴다. 기존 버전을 덮어쓰지 않는다.
- 대본에 가상의 인물 이름이나 “민수 씨” 같은 호칭을 붙이지 않는다. 사회 이슈는 짧고 생동감 있는 해설로 풀며, 조사 수치→차트 해석→원인 후보·반론으로 전개한다. 수치의 원문 문항·대상·시점·분모를 확인하고, 실제 조사와 가상 계산·편집자 해석을 구분한다. 해외 수치를 한국 전체에 일반화하거나 오래된 조사를 최신 조사로 소개하지 않는다.
- 홈서버 SSO를 유지한다. 비밀값·인증 쿠키를 출력하거나 커밋하지 않는다. 운영 인증 우회 옵션을 추가하지 않는다.

- 카테고리 로고는 첫 프레임부터 마지막 프레임까지 모든 프레임에 포함한다(2026-10-11 재확인). 컷 전환·페이드·인트로·엔딩에도 누락되지 않도록 전환 합성이 끝난 최종 영상 레이어에 고정 오버레이하고, 전체 프레임 검사를 수행한다.

- 2026-10-11 롱폼 피드백: 레퍼런스는 캐릭터·스타일을 일치시키기 위한 생성 입력이다. 최종 영상의 상황 컷으로 그대로 반복 사용하지 않는다. 대본의 행동·장소·비유에 맞는 이미지를 컷별로 내장 ImageGen에서 새로 생성하고 프롬프트·참조·해시를 보존한다. 자막은 Pretendard 계열의 가벼운 굵기와 얇은 단일 외곽선, 최대 2줄을 기본으로 한다. 굵은 Maple 이중 외곽선·팝 확대는 롱폼에 적용하지 않는다. 낭독 원문과 표시 자막을 분리하고 비율·금액·연도·인원·시간은 6%, 400만 원, 2026년처럼 숫자로 표시한다. 원문·기존 음성·과거 버전은 보존한다.
