## 기획과 사실

낭독 말투(2026-10-13): 친구에게 편안히 이야기하는 구어체를 전체에 적용한다. ‘~다/~습니다’가 연속되는 보고서 말투를 피하며 짧은 질문·반응·독백과 ‘~잖아요/~거든요/~죠’ 등을 자연스럽게 섞는다. 어미만 바꾸는 치환 작업으로 끝내지 않는다. 반말이나 ‘야/너’를 억지로 넣지 않으며 제목·출처·제작 메타데이터는 별도다.

30~40대 출퇴근 청취자를 대상으로 화면 없이도 이해되는 독립적인 롱폼을 우선 제작하고 핵심 구간을 이야기쇼츠로 재편집한다. 첫 승진 주제의 20분은 시험 목표이며 길이 채우기나 고정 편수를 요구하지 않는다. 기본 롱폼 16:9, 파생 쇼츠 9:16. 쇼핑용 6~8컷·상품 선정·구매 CTA를 강제하지 않는다.

2026-10-13 최신 사용자 방향: 친구와 수다 떨듯 사회·기업 문제를 재미있게 짚고, 공감과 상황의 모순을 중심에 둔다. 생활 장면→기대와 현실의 어긋남→이를 보여주는 데이터→짧은 관찰·농담→다음 궁금증으로 자연스럽게 연결한다. 통계마다 같은 순서를 반복하거나 원인 목록·반론·개인 체크리스트로 강의를 만들지 않는다. 결말은 기업의 보상·권한·인력·평가 설계나 사회 구조에서 바뀌어야 할 조건을 구체적으로 짚는다. 시청자에게 자기계발 과제나 교훈을 주지 않는다. 웃음은 시스템의 모순에서 만들며 사람·세대를 조롱하지 않는다.

데이터 설명도 대화체로 쓴다. 먼저 시청자가 알아듣는 질문을 던지고 숫자로 의외의 차이를 보여준다. 다른 문항의 6%와 76%를 사람들의 변덕이나 증가율로 다루지 않는다. 같은 자리도 보상과 시간이 함께 바뀌면 의미가 달라진다는 계산은 실제 조사와 구분해 자연스럽게 예시 조건을 말한다. 재미를 위해 수치를 부풀리거나 기업의 의도·통계가 증명하지 않은 원인을 단정하지 않는다.

가상 개인 이름(민수 씨 등)을 붙이지 않는다. 사실·창작 예시·편집 해석을 구분하고 조사 원문 문항·대상·시점·분모·원출처를 보존한다. 해외·오래된 자료를 한국 전체·최신 결과로 일반화하지 않는다. 필요한 해석 조건은 짧고 쉬운 말로 설명하고 상세 출처는 웹에 남긴다. 원문 대본과 표시 자막은 불변 버전으로 저장한다.

## 캐릭터와 화면

현재 story/seed.json의 승인된 정면 기준 ID와 캐릭터 가이드가 출발점이다. 《업》 느낌의 입체 스타일과 성인 남성·성인 여성·남자 어린이·여성 청소년의 4개 역할을 유지한다. 성인 여성은 날씬한 현대 여성·안경 없음·스커트 오피스룩, 딸은 고등학생·빨간 머리·검은 가죽 재킷·레깅스·액세서리의 비성적인 케이팝 스트리트 패션이다. X의 동물 가족과 혼용하지 않는다.

캐릭터당 정면 포함 각도 6·표정 4·상황 5장의 목표 레퍼런스를 관리한다. 옛 실패 얼굴·의상·나이를 새 생성의 기준으로 사용하지 않는다. 입력 참조는 상황 컷을 대신하지 않는다. 각 대사의 행동·장소·비유에 맞는 새 ImageGen 이미지와 참조·프롬프트·해시를 보존하고 손·얼굴·의상·대사 의미 일치를 검수한다. 차트의 수치·축·출처는 근거 자료로 직접 구성한다.

자막은 Pretendard 계열 가벼운 굵기/SemiBold·얇은 단일 외곽선·한 줄이다. 1080p 기준 62.4px(기존 52px 대비 20% 확대)을 적용하고 표시 폭을 넘으면 의미 단위로 나눈다. 낭독 철자와 표시용 6%, 400만 원, 2026년 등의 숫자를 분리해 전수 대조한다. Maple 굵은 이중 외곽선·팝은 롱폼에 적용하지 않는다. 진행 번호(01/12)·가상/설명용/편집자 꼬리표는 화면에 넣지 않고 필요한 예시 조건은 자연스러운 질문으로 설명한다. GumaStory 로고는 모든 프레임에 유지한다.

## 음성과 수정

현행 Story 롱폼 음성은 Gemini Flash TTS / Zephyr다. 일관된 단락 묶음의 내레이션이 편집 기준이며 영상·자막은 생성 후 실제 발화에 맞춘다. 기본 BGM은 없다.

컷 ID·낭독 원문/모델·프로필·참조 WAV/대본 SHA256·생성 작업 ID·음성 SHA256·길이를 기록한다. 번호만으로 음성을 연결하지 않는다. 같은 원문·설정·참조의 정상 컷은 재사용하고 변경/실패 컷만 새 테이크로 생성한다. 자막 글꼴·숫자 표시만 수정하면 음성을 재생성하지 않는다. 새 컷 길이에 맞춰 영상·자막 시간표를 다시 계산한다.

최종 컷 음성의 ASR 정렬과 실제 파형 활동 시간으로 음절당 발화·내부 쉼·문장/컷 경계 쉼을 구분해 검사한다. 알려진 문제 컷을 기준 계산에서 제외하고 기준을 동결한다. 숫자 ASR은 원문 낭독 철자와 대응하며 미정렬은 대기한다. 후보 문장/컷 수와 중복 유형 수를 구분하고 원하는 샘플 수에 맞춰 문턱을 조절하지 않는다. 자세한 실행·결과 상태는 발화 검수 문서를 따른다.

2026-10-12 과거 Sohee 비교 시험 이력: 약 5분 v2 음성 전체에 긴 무음 중간 축소·느린 문장의 피치 보존 속도 보정을 적용하는 v3는 사용자가 승인한 시험 편집이다. 문장 경계 약 0.45초·내부 쉼 약 0.22초, 최대 1.12배로 제한하고 원본·삭제/속도 구간·비선형 매핑·자막 정렬·전후 검사와 동결 기준을 보존한다. 이 수치를 다른 프로젝트의 기본 보정값으로 확대하지 않는다. Sohee v3는 보존된 과거 시험이며 현재 Story 롱폼 기본은 Gemini Flash / Zephyr이며 이 시험의 속도 보정은 기본값이 아니다. 실제 청취·개별 결과 승인 상태는 별도로 유지한다.

## 파생·공유

이야기쇼츠는 원본 ID·정확한 영상 버전·SHA256·시작/끝 구간을 기록한다. 한국어 화자 Sohee로 새 낭독하고 모바일 구도·후킹·자막을 다시 편집한다. 원본 수정으로 자동 덮어쓰지 않는다. 각 파생본의 제작·검수·업로드·공개 승인도 별도다.

파일은 storage/story에서 버전별 관리하고 웹 보관함 링크로 공유한다. 기존 tools/ 스냅샷·실패 테이크·대본·검수 이력은 보존한다. 파일 존재나 웹 등록만으로 실제 청취/사용자 승인/YouTube 등록을 완료로 기록하지 않는다.

## 2026-10-17 사용자 참고 영상 적용

참고: 역사본능 [9.11 사건](https://www.youtube.com/watch?v=Xeglv57PZcI), 역사에 반하다 [방주 모양 지형](https://www.youtube.com/watch?v=_qlYehTzfB4). 사실 자료가 아니라 서사와 화면 전달 방식의 참고다. 원문 대사·음성·화면을 재사용하지 않는다.

- 사건·물건·행동으로 시작하고 의외의 전개로 질문을 만든다. 강의식 목차와 같은 설명의 반복을 줄인다. 질문→단서→부분적인 답→다음 질문이 이어지도록 구성한다.
- 말하는 대상이 등장하는 실제 발화 시점에 화면을 맞춘다. 고정 초 단위로 관계없는 이미지를 순환하지 않는다. 전체→세부→비교→맥락의 순서로 시선을 안내한다.
- 숫자·시간·차이는 비례와 관계가 보이는 지도·연대선·비교 도표로 전달한다. 자료의 원문을 AI 생성 문자로 대체하지 않는다. 질문을 자막 위에 다시 띄우는 장식 키워드는 사용하지 않는다.
- 자연스러운 음성을 먼저 만든 뒤 화면을 붙인다. 같은 Zephyr 말투로 문맥 묶음을 생성하며 숫자 검수·대사 일치·묶음 간 속도와 음높이 편차를 검사한다. 무음 자동 분석을 실제 청취나 자연스러움 승인으로 기록하지 않는다.
- 샘플 프레임·ASR 분석 범위를 명시한다. 전체 영상을 보거나 실제로 들었다고 과장하지 않는다. 상세 분석과 작품별 적용표는 버전별 웹 리소스로 보관한다.

- 재현 기준: `storage/story/productions/dead-sea-scrolls-v4/`에 대본·음성·shot-plan·assets·captions와 `render.py`, `check_continuity.py`, `verify.py`, `publish.py`를 보관한다. 소스 이미지와 음성은 서버 리소스로 관리하며 Git에 대용량 바이너리를 넣지 않는다. 게시 전 검수 결과의 최종 파일 해시가 일치해야 한다.

## 2026-10-18 v5 자막·컷 길이·재사용 정정

- 자막은 확정 대본을 기준으로 작성하고 ASR은 발화 시점 정렬에 사용한다. 전사 결과를 검수 없이 표시하지 않는다. 맞춤법·띄어쓰기·고유명사·숫자·부정/가능성 표현을 원문과 대조하고, 글자 폭 때문에 조사를 앞 문장에서 떼거나 종속절만 남기지 않는다. 의미를 유지한 압축·재구분의 전후 문장을 웹에 기록한다. 무음 분석과 실제 청취는 구별한다.
- 모든 최종 이미지 컷은 최소 3초(24fps 72프레임), 최대 8초다. 짧은 대사가 나와도 3초 미만 삽입 컷을 만들지 않는다. 발화 의미를 유지하면서 경계 조정 또는 인접 장면의 유지로 해결한다.
- 동일 이미지는 줌·패닝·크롭·색상 변경 여부와 무관하게 전체 최대 2개 최종 컷에만 사용한다. 기존 v4의 연속 등장 묶음 집계만으로 통과시키지 않는다. 원본 해시와 계보로 최종 컷마다 집계하고 비슷한 생성 변형도 시각 검수한다.
- 같은 이미지가 연속되면 실제 카메라 움직임을 이어 하나의 컷으로 합칠 수 있지만 최대 8초를 넘기지 않는다. 길어지면 대사에 맞는 새 상황 이미지를 생성해 나눈다. 긴 한 컷으로 반복 제한을 우회하지 않는다. 도표가 있는 장면도 이번 v5에서는 3~8초 이미지 컷을 유지하고 설명 그래픽의 연속 시간은 별도로 관리한다.
- 내부 렌더 분할은 최종 컷과 구별한다. 도표 갱신용 내부 조각의 카메라 위치는 연속이어야 하며 새로운 이미지/컷으로 위장하지 않는다. 최종 편집표에서 컷 길이·원본별 사용 횟수·총 프레임·음성 동일성을 검증한다. v3/v4의 Zephyr 음성과 노란 한 줄 자막 디자인은 유지한다.
