# GumaStory 제작 기준

[통합 안내](guide-index.md), [Story AGENTS](../story/AGENTS.md), [발화 속도 검수](story-prosody-review.md)를 함께 읽는다. 쇼핑 전용 정책은 이 공간의 기본값이 아니다.

## 기획과 사실

30~40대 출퇴근 청취자를 대상으로 화면 없이도 이해되는 독립적인 롱폼을 우선 제작하고 핵심 구간을 이야기쇼츠로 재편집한다. 첫 승진 주제의 20분은 시험 목표이며 길이 채우기나 고정 편수를 요구하지 않는다. 기본 롱폼 16:9, 파생 쇼츠 9:16. 쇼핑용 6~8컷·상품 선정·구매 CTA를 강제하지 않는다.

짧고 생동감 있는 해설과 조사 수치→차트 해석→원인 후보·반론으로 전개한다. 가상 개인 이름(민수 씨 등)을 붙이지 않는다. 사실·창작 예시·편집 해석을 구분하고 조사 원문 문항·대상·시점·분모·원출처를 보존한다. 해외·오래된 자료를 한국 전체·최신 결과로 일반화하지 않는다. 원문 대본과 표시 자막은 불변 버전으로 저장한다.

## 캐릭터와 화면

현재 story/seed.json의 승인된 정면 기준 ID와 캐릭터 가이드가 출발점이다. 《업》 느낌의 입체 스타일과 성인 남성·성인 여성·남자 어린이·여성 청소년의 4개 역할을 유지한다. 성인 여성은 날씬한 현대 여성·안경 없음·스커트 오피스룩, 딸은 고등학생·빨간 머리·검은 가죽 재킷·레깅스·액세서리의 비성적인 케이팝 스트리트 패션이다. X의 동물 가족과 혼용하지 않는다.

캐릭터당 정면 포함 각도 6·표정 4·상황 5장의 목표 레퍼런스를 관리한다. 옛 실패 얼굴·의상·나이를 새 생성의 기준으로 사용하지 않는다. 입력 참조는 상황 컷을 대신하지 않는다. 각 대사의 행동·장소·비유에 맞는 새 ImageGen 이미지와 참조·프롬프트·해시를 보존하고 손·얼굴·의상·대사 의미 일치를 검수한다. 차트의 수치·축·출처는 근거 자료로 직접 구성한다.

자막은 Pretendard 계열 가벼운 굵기/SemiBold·얇은 단일 외곽선·최대 2줄이다. 낭독 철자와 표시용 6%, 400만 원, 2026년 등의 숫자를 분리해 전수 대조한다. Maple 굵은 이중 외곽선·팝은 롱폼에 적용하지 않는다. 진행 번호(01/12)·가상/설명용/편집자 꼬리표는 화면에 넣지 않고 필요한 예시 조건은 자연스러운 질문으로 설명한다. GumaStory 로고는 모든 프레임에 유지한다.

## 음성과 수정

2026-10-12 최신 사용자 채택: Story·롱폼은 첫 승진 영상에서 청취한 Gemini Zephyr를 사용하며 로컬 TTS를 사용하지 않는다. 신규 기본 모델은 gemini-3.8-flash-tts(gemini-flash), 화자는 Zephyr다. 첫 영상은 Flash 89구간·Flash-Lite 25구간의 혼합본이므로 이를 단일 모델 제작본으로 기록하지 않는다. 한도 부족 시 Lite·로컬로 자동 전환하지 않고 남은 구간을 보존해 재개한다. 쇼핑·이야기쇼츠·X의 기존 로컬 정책은 변경하지 않는다. 컷/음성 구간별 원본·작업 ID·해시·새 테이크를 관리하고 정상 구간은 재사용한다. 30~60초 음성 구간과 시각 컷을 별도로 연결할 수 있다. 모델 채택은 기존 영상 재제작·업로드·공개 승인과 다르다. 기본 BGM은 없다.

컷 ID·낭독 원문/모델·프로필·참조 WAV/대본 SHA256·생성 작업 ID·음성 SHA256·길이를 기록한다. 번호만으로 음성을 연결하지 않는다. 같은 원문·설정·참조의 정상 컷은 재사용하고 변경/실패 컷만 새 테이크로 생성한다. 자막 글꼴·숫자 표시만 수정하면 음성을 재생성하지 않는다. 새 컷 길이에 맞춰 영상·자막 시간표를 다시 계산한다.

최종 컷 음성의 ASR 정렬과 실제 파형 활동 시간으로 음절당 발화·내부 쉼·문장/컷 경계 쉼을 구분해 검사한다. 알려진 문제 컷을 기준 계산에서 제외하고 기준을 동결한다. 숫자 ASR은 원문 낭독 철자와 대응하며 미정렬은 대기한다. 후보 문장/컷 수와 중복 유형 수를 구분하고 원하는 샘플 수에 맞춰 문턱을 조절하지 않는다. 자세한 실행·결과 상태는 발화 검수 문서를 따른다.

Sohee 친근한 진행자는 CustomVoice **비교 시험**이다. 약 5분 v2 음성 전체에 긴 무음 중간 축소·느린 문장의 피치 보존 속도 보정을 적용하는 v3는 사용자가 승인한 시험 편집이다. 문장 경계 약 0.45초·내부 쉼 약 0.22초, 최대 1.12배로 제한하고 원본·삭제/속도 구간·비선형 매핑·자막 정렬·전후 검사와 동결 기준을 보존한다. 이 수치를 다른 프로젝트의 기본 보정값으로 확대하지 않는다. Sohee v3는 보존된 과거 시험이며 현재 기본은 Gemini Zephyr다. 실제 청취·개별 결과 승인 상태는 별도로 유지한다.

## 파생·공유

이야기쇼츠는 원본 ID·정확한 영상 버전·SHA256·시작/끝 구간을 기록한다. 선택 여성 F4로 새 낭독하고 모바일 구도·후킹·자막을 다시 편집한다. 원본 수정으로 자동 덮어쓰지 않는다. 각 파생본의 제작·검수·업로드·공개 승인도 별도다.

파일은 storage/story에서 버전별 관리하고 웹 보관함 링크로 공유한다. 기존 tools/ 스냅샷·실패 테이크·대본·검수 이력은 보존한다. 파일 존재나 웹 등록만으로 실제 청취/사용자 승인/YouTube 등록을 완료로 기록하지 않는다.
