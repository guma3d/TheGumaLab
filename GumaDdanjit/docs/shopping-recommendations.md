# 구마의 딴짓 쇼핑 아이템 추천 기준

2026-10-12 사용자 요청. Food·Tech·Living 공통이며 각 카테고리의 기존 상품·자료·링크 검증 기준과 함께 적용한다.

- 무작위 상품 나열보다 구마가 일상에서 발견하고 써보고 싶어지는 이유가 있는 아이템을 고른다. 판매 독촉보다 구체적인 사용 상황·궁금증·매력·한계를 편안한 말투로 전달한다.
- 조사 시점 기준 최근 7일 이내 실제 화제 근거가 있는 제품 **또는** 현재 계절·사회 분위기에 잘 맞는 아이템을 선정한다. 화제형/계절형/사회 맥락형을 구분하고 추천 이유를 설명한다.
- 최근 화제는 원출처·게시일·사건일·확인 시각을 저장한다. 오래된 기사·누적 리뷰를 최근 유행으로 바꾸지 않는다. 계절/사회 맥락은 실제 생활 상황과의 관련성을 설명하고 근거 없이 유행/판매 급증을 주장하지 않는다.
- 사용해 본 듯 편안하고 구체적인 이야기 톤을 지향한다. 실제로 사용·구매·시식했다고 꾸미지 않는다. 사용자가 제공한 실제 경험·장단점은 의미와 강도를 보존하며, 없는 개인 총평은 사용자 의견 대기로 둔다. 검증된 특징·확인된 한계·후기에서 조사한 의견을 자신의 체험과 구분한다.
- 기존 제작·추천·최근 게시 이력과 중복을 확인한다. 새 후보마다 정확한 제품/옵션·현재 가격/판매 상태·발급 제휴 링크 여부·공식 판매처/로켓배송·제품 설명 근거·영상 자료 확보/권리 상태를 기록한다. Tech의 50만원 이하와 전용 이미지 합성 기준, Food 실제 외형/조리 근거, Living 동일 모델 실사용 자료/rednote 필수 조사 기준을 유지한다.
- 보고에는 제품명/정확한 옵션, 지금 추천하는 이유, 근거 링크·날짜, 자연스러운 도입 예시, 검증된 특징/한계, 실제 사용자 평가가 필요한 항목, 가격·구매 링크 검증, 화면 자료 확보 가능성을 포함한다. 증거가 부족한 항목은 미확인/후보로 남기고 확정 추천처럼 포장하지 않는다.
- Food 검색 우선순위(2026-10-17): 사용자가 브리치즈의 반응과 제품 응용을 긍정적으로 평가했다. 제품을 간단히 조리·조합해 새로운 메뉴로 바꾸는 후보를 우선한다. 제품→실제 조리 동작→먹음직스러운 완성 결과가 명확하고 재료·도구·난도가 적절한지 비교한다. 소재의 보는 재미도 평가한다. 펼치기·뒤집기·바르기·터뜨리기·쌓기 등 실제 제품에 맞는 서로 다른 행동과 작은 생활 상황을 제안하고, 같은 접시/붓기 접사만으로 구성되는 후보는 우선순위를 낮춘다. 응용성은 최근 화제·계절 맥락과 함께 판단하며, 사용자 평가를 검증된 조회수/판매 성과나 성공 보장으로 확대하지 않는다. 제휴·로켓배송·제작 자료 검증은 생략하지 않는다.
- 추천 개수는 현재 사용자 요청을 따른다. 조사는 유료 생성·제작·업로드 승인이 아니다. 결과는 통합 storage에 날짜/버전별로 보존하고 담당 대화에서 보고한다.
