## 보존과 적용 한계

- Story에서 동시에 진행하던 코드·발화 검수·Sohee 편집 지침은 보존했다. 이 점검은 그 시험을 기본 화자 채택이나 실제 청취 수용으로 변경하지 않는다.
- 과거 서비스 폴더/버전 스냅샷/제작 승인/검수/원본은 역사·복구 자료로 보존한다. 현재 작업의 시작점은 [통합 안내](guide-index.md)다.
- 쇼핑 단일 생성은 검증된 인계 도구로 운영한다. 기존 컷별 shopping.py/tts_engine.py 자동 경로를 전체 개편하지 않았다. 새 제작은 해당 경로를 사용하지 않으며 모델·참조·연속 마스터 실제 적용을 검수한다. Story/X는 app 규칙 JSON만으로 자동 강제되지 않는다.
- ACTIVE 자동화 gumavideofactory-3는 이미 통합 지침/대상 모듈/고정 참조를 읽는다. 새 공통 AGENTS를 통해 안내 문서도 읽도록 연결했다. PAUSED 과거 완료 알림의 옛 경로는 비활성 이력이며 다시 실행할 때 상태와 경로를 재확인한다. 종료한 shorts 1회 점검을 재생성하지 않았다.
- 새 유료 생성·YouTube 변경·외부 세션 메시지 발송은 이 정리 작업에 포함하지 않았다.

변경 전 활성 문서는 로컬 backups/guidance-audit-20261012에 저장했다. 비밀 파일/대형 미디어·DB를 복사하거나 커밋하지 않았다.
