# 통합 제작 지침 안내

정리 기준일: 2026-10-12. Main과 모든 제작 세션의 시작점이다. 작품별 진행 상태는 지속 규칙과 분리한다.

## 작업 전에 읽을 순서

1. 상위 TheGumaLab AGENTS → [통합 공통 지침](../AGENTS.md) → 이 문서.
2. 아래 표에서 대상 공간의 AGENTS와 상세 제작 기준을 읽는다. Main도 대상 공간을 작업할 때 생략하지 않는다.
3. 해당 아이템의 최신 대본·콘티·완료/실패 기록·사용자 승인 버전·해시를 실제 저장소와 대화에서 확인한다. [Main 인계](../../CODEX_MAIN_HANDOFF.md)는 날짜가 있는 요약이며 현재 상태를 보장하지 않는다.
4. 코드·생성 요청·실제 출력이 정책과 일치하는지 확인한다. 문서나 JSON 변경만으로 기존 제작기가 새 정책을 자동 실행한다고 간주하지 않는다.

## 규칙의 범위와 변경

Food·Tech·Living 아이템 조사는 [구마의 딴짓 추천 기준](shopping-recommendations.md)을 함께 읽는다. 최근 7일 화제 또는 현재 계절/사회 맥락을 검증하고 개인적인 추천 톤과 실제 사용 경험을 구분한다.

- 사용자의 최신 명시적 지시를 해당 범위에 적용한다. 기존 승인 범위를 유지하고 이미 승인한 작업에 재승인을 요구하지 않는다. 특정 작품 시험을 전 프로젝트 기본값으로 확대하지 않는다.
- 공통 지침은 저장·승인·출처·검수·보안·브랜딩이다. 음성의 생성 단위, 자막, BGM, 화면 제작법은 공간/카테고리별 기준을 따른다.
- 새 피드백은 공통인지 공간/작품 한정인지 기록한 뒤 담당 AGENTS·상세 문서·관련 실행 규칙을 함께 갱신한다. 폐기 규칙은 활성 문서에서 제거하고 이전 결과·승인·검수 기록은 그대로 보존한다.
- 비교 시험, 기술 검사, 실제 청취, 사용자 수용, 업로드, 공개는 서로 다른 상태다. 서로 대신 기록하지 않는다.
- Main이 전체를 조율하고 Food·Tech·Living은 쇼핑 조사/콘티를 담당한다. Story·X의 별도 작업과 최신 사용자 지시도 확인한다. 다른 세션에 메시지를 보내는 것은 별도 사용자 허가가 있을 때만 한다.

## 음성·화면 기준 요약

| 대상 | 신규 음성 | 생성 단위 | BGM / 자막 |
| --- | --- | --- | --- |
| Food·Tech·Living | Qwen Base qwen-clone-1.7b, F4-dates-v1 고정 참조 | 전체 대사 한 번, 연속 마스터 | 기존 5곡 중 무작위 1곡, 고정 음량 / Maple Bold 팝 |
| Story 롱폼 | Qwen Base qwen-clone-1.7b, M5-fixed-v1 고정 참조 | 컷별, 동일 대사·설정·참조 해시의 정상 컷 재사용 | 기본 음악 없음 / Pretendard 얇은 외곽선, 최대 2줄, 숫자 표시 |
| 파생 이야기쇼츠 | 선택 여성 F4, M5 원본을 그대로 쓰지 않고 새 낭독 | 해당 편집본의 승인 대본·설정 기록 | 쇼핑용 6~8컷·구매 CTA 틀을 강제하지 않음 |
| X 신규 내레이션 | 선택 여성 F4, GumaTTS 경유 | 작품의 승인된 제작 계획에 따름 | 작품별 BGM·효과음 / Maple Bold 기준 |

쇼핑의 F4 단일 생성과 Story의 M5 컷별 생성은 혼합하지 않는다. 이야기쇼츠·X에 쇼핑 전용 참조/생성 단위를 임의 확대하지 않는다. X 몽쉘 v8/v9의 기존 Zephyr는 변경 없는 음성 보존 지시의 예외이며 새 프로젝트 기본값이 아니다.

Sohee CustomVoice는 Story의 약 5분 비교 시험이다. 그 v2 음성을 대상으로 한 무음·속도 편집 v3 요청도 시험 범위다. 명시적 채택 전까지 기본 M5를 바꾸지 않는다. VoiceDesign은 선정 참조의 출발점·비교 기능이며 쇼핑/Story의 매 컷 신규 화자 설계 기본값이 아니다.

Tech의 imagegen+일반 편집 합성, 컷 내부 카메라 고정 및 Blender/Veo/씨댄스 금지는 **Tech 전용**이다. Food·Living·Story·X에 확대하지 않는다. X의 연속 애니메이션과 Story의 새 상황 이미지 기준은 각 문서를 따른다.

## 저장·검수·게시

- 공통 웹은 리소스 / 이미지 콘셉트 / 완성 영상의 읽기 전용 버전 보관함이다. 피드백·제작/공개 승인 입력 UI는 없으며 Codex 대화로 받는다. 대본·출처·참조 음성도 리소스에 보존한다.
- 원본·버전·해시·모델/생성 작업 ID·출처·권리 근거·검수·사용자 승인 범위를 로컬과 웹에 연결한다. 대형 미디어·DB·비밀값은 커밋하지 않는다.
- 승인된 GumaShop / GumaStory / GumaX PNG 로고를 왼쪽 상단 최종 레이어로 **첫~마지막 모든 프레임**에 적용한다. 전환·페이드도 검사한다.
- 실제 청취/시각 검수 여부를 정직하게 기록한다. ASR·음량·해시·디코딩 통과가 자연스러움이나 콘텐츠 수용을 뜻하지 않는다. 실패 컷·미확인 항목은 대기 상태로 남긴다.
- 정확한 결과물에 대한 사용자 요청 없이 YouTube 비공개/일부 공개 업로드도 하지 않는다. 업로드와 공개는 별도다. 낮은 조회수만으로 삭제·재업로드하지 않는다.
- 쇼핑 설명: 글머리 상품 정보·상품 모음/검증한 구매 링크·#광고 및 관련 태그 5개 이상·실제 음원의 간결한 출처·수수료 고지 원문 마지막 줄. 제목 앞 [광고] 반복은 없음. 영상 [광고]·유료 프로모션/해당 AI 설정·웹 구매 링크 주변 고지는 유지한다. 비광고 이야기 콘텐츠에 쇼핑 고지나 상품을 억지로 넣지 않는다.
- 공개 상품 모음 등록과 링크 변경은 요청 범위에 따라 실행하고 실제 옵션·도착·추적 정보를 확인한다. 정상 연결을 구매 수익 보장으로 설명하지 않는다.

## 실행 지침과 이력 구분

[production_rules.json](../app/core/production_rules.json)은 app 쇼핑/파생 카테고리의 프롬프트와 버전 스냅샷이다. Story·X의 전체 규칙을 자동 강제하는 전역 엔진이 아니다. 수동 제작도 해당 공간의 검수를 적용한다. 기존 파일의 스냅샷은 수정하지 않는다.

현재 ACTIVE 상태 확인 자동화는 통합 경로를 사용한다. PAUSED 상태의 과거 완료 알림에 남은 옛 경로는 역사 기록으로 두며 다시 활성화할 때 새 기준·아이템 상태·완료 여부를 재확인한다. 10월 12일 쇼츠 1회 후속 점검은 종료되었으므로 재생성하지 않는다.
