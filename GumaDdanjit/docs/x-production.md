## 지속되는 제작 기준

- 실험적인 고퀄 영상 공간이다. 현재 상품 동화의 규칙을 모든 실험 주제로 확대하지 않되 상품 작품은 실제 상품이 주인공이어야 한다.
- 현재 동물 가족은 호랑이 아빠·토끼 엄마·돼지 큰아들·고양이 작은딸이다. Story 사람 가족과 레퍼런스를 혼합하지 않는다. 엄마가 주로 쿠킹하고 필요한 인물만 등장한다.
- 공식 사진/검증 가능한 자료로 제품 외형·코팅·장식·단면·비율을 고정한다. 실제 없는 토핑·크림·색상을 추가하지 않는다. 물리 크기를 컷 간 유지하되 픽셀 면적을 고정하거나 다양성을 없애지 않는다. 탑뷰·매크로·손·시식 등 다양한 샷으로 구성한다. 지정된 마법 축소 전후의 형태·크기 연결을 검수한다.
- 창작 제조 동화는 실제 공정이나 완제품의 필수 조리법으로 소개하지 않는다. 제조 시작/중간/완료 순서를 검수한다.
- 모든 컷에 인물·재료·제품의 실제 연속 애니메이션이 있어야 한다. 정지 이미지 줌/팬 대체본을 새 완성 영상으로 등록하지 않는다. 요청된 오프닝·시식·엔딩을 임의 제외하지 않는다.
- 생성 영상의 얼굴/입을 사후 보정하는 방식은 사용자 금지다. 불합격 컷은 새 생성/승인된 새 콘셉트로 수정한다. 통상적인 컷 연결과 최종 로고 합성은 유지한다. 입을 대화하듯 움직이는 캐릭터 연출을 피하고 외부 내레이터와 구분한다.
- 시식은 코 아래 실제 입술 접촉→한입→같은 손의 제품 유지 순서다. 입 위치 변화·코/볼 접촉·손 바뀜·순간이동을 허용하지 않는다.
- 신규 내레이션은 선택 여성 F4를 GumaTTS로 생성한다. 기존 몽쉘 v8/v9의 사용자 수용 Zephyr는 엔딩만 수정할 때 보존한다. 쇼핑의 전체 대사 단일 생성 규칙을 X의 모든 작품에 임의 적용하지 않는다.
- 작품별 승인된 발랄한 BGM·제조/마법/시식 효과음을 관리한다. 사용 음원의 권리와 간결 출처를 유지한다. Story의 기본 무음악 정책을 적용하지 않는다.
- MapleBold 이중 외곽선·핵심어 색 강조·짧은 팝과 컷별 안전 배치를 사용한다. GumaX 로고를 모든 프레임 왼쪽 상단에 적용한다.
- 별도 생성 실사 느낌 썸네일을 실제 상품과 대조하고 버전/프롬프트/해시를 보존한다. 영상 프레임 추출이나 영상 삽입으로 대체하지 않는다.
- 결과 이미지·영상·검수 프레임은 **웹과 텍스트 링크로만 공유**한다. 과거 한 번의 채팅 표시 허용은 지속 허가가 아니다. 자동 이미지 표시가 발생하는 도구는 이 제약을 고려한 승인된 생성 경로를 사용한다. Google 크레딧 이미지/영상 API 사용 허용 이력은 해당 작품 요청 범위에서 확인한다. Tech 전용 영상 생성 금지를 X로 확대하지 않는다.
- 유료 생성은 요청 범위·예산·실패 원인을 확인한다. 무제한 재시도·자동 유료 우회는 하지 않는다. 완료/미채택 출력과 차단/실패·환불·이미지 비용을 구분하고 Flow 크레딧·API 할당량·GCP 크레딧을 혼동하지 않는다. 과거 잔액·한도·단가는 날짜가 있는 관측이며 필요할 때 재조회한다.
