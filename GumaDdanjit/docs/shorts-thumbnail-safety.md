# 쇼츠 썸네일 텍스트 잘림 방지

2026-10-12 사용자 피드백. 앞으로 만드는 **모든 쇼츠 썸네일**에 적용한다. GumaShop Food·Tech·Living, 파생 이야기쇼츠, GumaX 쇼츠를 포함한다. 기존 파일은 보존하며 기존 게시본 교체는 요청 범위에 따라 별도로 처리한다.

실제 첨부 사례: 누룽지팝 모바일 카드에서 맨 위 문구 상단이 잘렸으며 하단에는 YouTube 제목이 이미지 위에 표시됐다. 원본 이미지 잘림과 표시 크롭/UI 겹침을 구분해 검사한다. 이번 요청은 앞으로의 제작 기준 등록이며 기존 누룽지팝 게시본을 자동 변경하는 요청으로 확대하지 않는다.

## 제작 기준

- 원본 전체가 보인다는 가정으로 가장자리에 문구를 배치하지 않는다. 제목·제품명·숫자·핵심어와 그 외곽선/그림자까지 중앙 안전 영역 안에 넣는다. 상품의 핵심 식별 부분도 예상 크롭에 남겨둔다.
- 9:16 원본의 보수적 시작값은 텍스트 전체 경계 **가로 12~88%, 세로 37~63%**다. 1080×1920이면 대략 x=130~950, y=710~1210이다. 이는 우리 제작용 기준이며 YouTube가 보장하는 공식 안전 영역이 아니다. 다른 원본 비율은 아래 크롭 공통 영역을 계산해 사용한다.
- 간결한 1~2줄과 모바일에서 읽히는 글자 크기·대비를 우선한다. 긴 문구는 줄이거나 자연스럽게 줄바꿈한다. 공간에 맞추려고 글자를 과도하게 축소하지 않는다. 단어/숫자/조사를 가장자리에서 자르거나 제품을 가리는 배치는 실패다.
- 표시되는 YouTube 제목·채널/시간/재생 표시·모서리 라운드 등 UI도 별도로 고려한다. 하단 제목이 놓이는 영역을 핵심 문구 자리로 사용하지 않는다. 크롭에 살아남더라도 UI와 겹쳐 읽히지 않으면 실패다. UI 영역은 실제 화면별로 확인하며 고정 픽셀값을 전 화면 보장값으로 가정하지 않는다.
- 생성 프롬프트에 중앙 안전 영역·짧은 문구·가장자리 텍스트 금지를 명시한다. 프롬프트에 적었다는 사실만으로 통과시키지 않고 실제 결과의 철자·문구·텍스트 경계를 시각 검수한다.

## 크롭·작은 화면 검수

1. 정확한 최종 썸네일 파일로 검수용 **9:16 / 3:4 / 1:1 / 16:9 중앙 cover 크롭**을 만든다. 이 비율들은 스트레스 검수용이며 모든 YouTube 화면이 이 비율이라고 단정하지 않는다.
2. 원본 비율이 r, 출력 비율이 t이면 t<r일 때 가로를, t>r일 때 세로를 가운데에서 잘라낸다. 각 크롭의 원본 좌표 공통 영역을 구하고 핵심 텍스트를 그 안에 여유 있게 둔다. 실화면에서 중앙이 아닌 크롭이 관찰되면 해당 조건도 추가한다.
3. 크롭본을 모바일 카드 크기로 줄여 문구가 끝까지 읽히는지 확인한다. 텍스트 외곽선/그림자·제품명·핵심어가 조금이라도 잘리면 **수정 필요**다. 원본 한 장 검수나 파일 해시 확인만으로 통과하지 않는다.
4. 원본·프롬프트·크롭 미리보기·정확한 Thumbnail/Video 버전·SHA256·시각 검수자/일시·관찰 결과를 버전 기록에 연결한다. 모바일 실제 표시 미확인은 별도 상태로 남긴다.
5. 사용자가 게시를 요청한 뒤 실제 계정에서 썸네일 적용 가능 여부와 저장 결과를 확인한다. 채널 Shorts 목록·검색 등 표시되는 화면과 모바일 카드에서 텍스트 잘림/다른 프레임 표시를 재확인한다. 준비한 이미지와 실제 표시된 썸네일이 다르면 적용 완료로 기록하지 않는다. 계정 UI 제약을 임의 영상 삽입·삭제/재업로드로 우회하지 않는다.

## 적용과 기록

크롭 검수 실패는 신규 썸네일 검수 완료로 기록하지 않는다. 실제 YouTube 화면 확인은 업로드/공개 승인을 대신하지 않으며 게시 전에는 크롭 시뮬레이션 통과·실화면 확인 대기를 구분한다. 웹/로컬의 이전 썸네일을 덮어쓰지 않고 수정본을 새 버전으로 저장한다. 승인된 별도 생성 썸네일·실제 상품 일치·영상에 썸네일 미삽입 규칙은 유지한다.

YouTube의 현재 적용 경로·계정별 제약은 [공식 썸네일 도움말](https://support.google.com/youtube/answer/72431)을 확인한다. 숫자 안전 영역과 크롭 스트레스 검사는 이 프로젝트의 예방 기준이다.
