# 4개 시즌 게임 상세 기획서

## 이어받기 안내

게임 구현은 시즌 1~4까지 완료되어 있다.  
다른 PC에서 이어서 작업할 때는 `HANDOFF.md`의 검증 명령으로 실행 상태를 먼저 확인한다.

## 공통 목표

48챕터 PDF 교재를 만들기 전에, 아이가 직접 업그레이드할 수 있는 4개의 완성된 게임을 먼저 만든다.

각 게임은 처음부터 실행 가능한 완성본이어야 한다.  
아이는 복잡한 엔진 코드를 보지 않고, `upgrade_zone.py`의 작은 코드만 바꾸며 결과를 확인한다.

## 공통 실행 구조

```text
python_kids_course/
  games/
    season_01_treasure_score/
      main.py
      upgrade_zone.py
      engine.py
      assets/
      README.md
    season_02_dungeon_choice/
      main.py
      upgrade_zone.py
      engine.py
      assets/
      README.md
    season_03_monster_battle/
      main.py
      upgrade_zone.py
      engine.py
      assets/
      README.md
    season_04_mini_adventure/
      main.py
      upgrade_zone.py
      engine.py
      assets/
      README.md
```

## 공통 파일 역할

| 파일 | 역할 | 아이가 직접 보는 정도 |
|---|---|---|
| `main.py` | 게임 실행 시작점 | 가끔 실행만 함 |
| `upgrade_zone.py` | 챕터별로 아이가 바꾸는 코드 | 주로 봄 |
| `engine.py` | 화면, 캐릭터, 점수 처리 등 미리 만든 코드 | 보지 않음 |
| `assets/` | 이미지, 사운드, 폰트 | 보지 않음 |
| `README.md` | 부모용 실행 설명 | 부모가 봄 |

## 공통 디자인 원칙

- 게임 화면은 한눈에 이해되어야 한다.
- 키보드 조작은 방향키, 스페이스, 엔터 정도만 사용한다.
- 초반에는 코드 1줄만 바꿔도 눈에 보이는 변화가 생겨야 한다.
- 코드 실행 결과는 즉시 보여야 한다.
- 에러가 나도 부모가 쉽게 원래 상태로 되돌릴 수 있어야 한다.
- 각 챕터의 업그레이드 코드는 명확한 주석 박스로 표시한다.

예시:

```python
# =========================
# 오늘의 업그레이드
# 아래 한 줄만 바꿔보자!
# =========================
hero_name = "번개용사"
```

# 시즌 1: 보물 점수 게임

## 사용 챕터

1~12챕터

## 게임 콘셉트

작은 주인공이 화면 안에서 보물을 먹으며 점수를 올리는 게임이다.  
함정에 닿으면 체력이 줄고, 보너스 보물을 먹으면 점수가 크게 오른다.

## 화면 구성

- 왼쪽: 주인공 캐릭터
- 화면 곳곳: 보물, 보너스 보물, 함정
- 상단: 이름, 점수, 체력, 속도
- 하단: 주인공 대사 또는 안내 메시지

## 기본 조작

| 키 | 동작 |
|---|---|
| 방향키 | 이동 |
| 스페이스 | 보물 줍기 또는 대사 보기 |
| R | 다시 시작 |

## 시즌 1에서 배울 감각

- 코드를 바꾸면 화면 문장과 숫자가 바뀐다.
- 변수는 게임 속 값이다.
- 계산은 점수와 체력을 움직인다.
- 문자열은 캐릭터의 이름과 대사다.

## `upgrade_zone.py` 예상 구조

```python
# 챕터 1~3: 글자 업그레이드
start_message = "모험 시작!"
hero_name = "번개용사"
hero_message = "보물을 찾자!"

# 챕터 4~7: 숫자 업그레이드
start_score = 10
hp = 100
speed = 5

# 챕터 8~12: 계산 업그레이드
treasure_point = 10
trap_damage = 20
bonus_multiplier = 2
```

## 챕터별 업그레이드

| 챕터 | 업그레이드 | 아이가 바꾸는 부분 | 결과 |
|---:|---|---|---|
| 1 | 시작 문장 | `start_message` | 시작 화면 문구 변경 |
| 2 | 주인공 대사 | `hero_message` | 하단 대사 변경 |
| 3 | 주인공 이름 | `hero_name` | 상태창 이름 변경 |
| 4 | 시작 점수 | `start_score` | 처음 점수 변경 |
| 5 | 점수 변수 | `score` | 점수판 값 확인 |
| 6 | 체력 | `hp` | 체력바 길이 변경 |
| 7 | 이동 속도 | `speed` | 캐릭터 이동 속도 변경 |
| 8 | 등장 문장 | `hero_name + " 등장!"` | 이름이 들어간 문장 표시 |
| 9 | 상태창 문장 | f-string | 이름과 점수 동시 표시 |
| 10 | 보물 점수 | `score = score + treasure_point` | 보물 점수 증가량 변경 |
| 11 | 함정 데미지 | `hp = hp - trap_damage` | 함정 피해량 변경 |
| 12 | 보너스 배율 | `score * bonus_multiplier` | 보너스 점수 변경 |

## 시즌 1 완료 결과

아이는 "게임 안의 글자와 숫자는 코드로 바꿀 수 있다"는 감각을 얻는다.

# 시즌 2: 던전 선택 게임

## 사용 챕터

13~24챕터

## 게임 콘셉트

던전 안에서 이름을 입력하고, 무기를 고르고, 열쇠와 비밀번호로 문을 여는 선택 게임이다.  
조건문을 사용해 "어떤 일이 일어나야 하는지"를 업그레이드한다.

## 화면 구성

- 중앙: 던전 방 또는 문
- 왼쪽: 플레이어 상태
- 오른쪽: 가진 열쇠, 보석, 무기
- 하단: 질문, 입력창, 결과 메시지

## 기본 조작

| 키 | 동작 |
|---|---|
| 키보드 글자 | 이름, 무기, 비밀번호 입력 |
| 엔터 | 선택 확정 |
| R | 다시 시작 |

## 시즌 2에서 배울 감각

- 입력은 플레이어가 게임에 보내는 말이다.
- 조건문은 게임의 규칙이다.
- 비교는 문이 열릴지 닫힐지 결정한다.
- `and`, `or`는 여러 조건을 합치는 방법이다.

## `upgrade_zone.py` 예상 구조

```python
secret_password = "1234"
required_level = 5

has_key = True
has_gem = False
red_key = False
blue_key = True

weapon = "검"
hp = 100
```

## 챕터별 업그레이드

| 챕터 | 업그레이드 | 아이가 바꾸는 부분 | 결과 |
|---:|---|---|---|
| 13 | 이름 입력 | `input()` | 입력한 이름으로 입장 |
| 14 | 무기 입력 | `weapon = input(...)` | 무기 이름 표시 |
| 15 | 공격력 입력 | `int(input(...))` | 숫자로 데미지 계산 |
| 16 | 열쇠 문 | `if has_key:` | 열쇠가 있으면 문 열림 |
| 17 | 비밀번호 문 | `password == secret_password` | 맞으면 통과 |
| 18 | 실패 메시지 | `else` | 틀리면 잠김 메시지 |
| 19 | 무기 선택 | `elif` | 무기마다 다른 결과 |
| 20 | 위험 체력 | `hp < 30` | 체력 낮으면 경고 |
| 21 | 레벨 제한 | `level >= required_level` | 레벨 조건 통과 |
| 22 | 이중 잠금 | `has_key and has_gem` | 둘 다 있어야 문 열림 |
| 23 | 아무 열쇠 | `red_key or blue_key` | 하나만 있어도 통과 |
| 24 | 보물상자 규칙 | 조건문 종합 | 조건에 따라 보상 변경 |

## 시즌 2 완료 결과

아이는 "게임은 조건에 따라 다른 일이 일어난다"는 감각을 얻는다.

# 시즌 3: 몬스터 배틀 게임

## 사용 챕터

25~36챕터

## 게임 콘셉트

몬스터와 턴제로 싸우는 전투 게임이다.  
반복 공격, 카운트다운, 아이템 가방, 몬스터 카드로 반복문과 자료 구조를 배운다.

## 화면 구성

- 왼쪽: 플레이어
- 오른쪽: 몬스터
- 상단: 턴, 플레이어 HP, 몬스터 HP
- 하단 왼쪽: 전투 로그
- 하단 오른쪽: 아이템 가방

## 기본 조작

| 키 | 동작 |
|---|---|
| A | 공격 |
| I | 아이템 보기 |
| U | 물약 사용 |
| R | 다시 시작 |

## 시즌 3에서 배울 감각

- 반복문은 같은 행동을 여러 번 하게 만든다.
- 리스트는 아이템 가방이다.
- 딕셔너리는 몬스터 카드다.
- 전투는 반복, 조건, 숫자가 함께 움직이는 구조다.

## `upgrade_zone.py` 예상 구조

```python
monster_hp = 30
player_power = 5

bag = ["물약", "검", "열쇠"]

monster = {
    "name": "슬라임",
    "hp": 30,
    "power": 5,
}
```

## 챕터별 업그레이드

| 챕터 | 업그레이드 | 아이가 바꾸는 부분 | 결과 |
|---:|---|---|---|
| 25 | 계속 공격 | `while monster_hp > 0` | 몬스터가 쓰러질 때까지 반복 |
| 26 | 턴 세기 | `turn = turn + 1` | 몇 턴 걸렸는지 표시 |
| 27 | 연속 공격 | `for i in range(5)` | 정해진 횟수 공격 |
| 28 | 보스 카운트다운 | `range(3, 0, -1)` | 3, 2, 1 표시 |
| 29 | 탈출 | `break` | 특정 조건이면 전투 종료 |
| 30 | 함정 건너뛰기 | `continue` | 함정 턴은 보상 계산 생략 |
| 31 | 아이템 가방 | 리스트 | 시작 아이템 변경 |
| 32 | 첫 아이템 | `bag[0]` | 첫 번째 아이템 표시 |
| 33 | 보상 줍기 | `append()` | 새 아이템 추가 |
| 34 | 아이템 버리기 | `remove()` | 필요 없는 아이템 제거 |
| 35 | 가방 둘러보기 | `for item in bag` | 모든 아이템 표시 |
| 36 | 몬스터 카드 | 딕셔너리 | 몬스터 이름/체력/공격력 변경 |

## 시즌 3 완료 결과

아이는 "반복과 자료 모음으로 게임이 풍성해진다"는 감각을 얻는다.

# 시즌 4: 미니 어드벤처 게임

## 사용 챕터

37~48챕터

## 게임 콘셉트

앞의 시즌에서 배운 기능을 합쳐 작은 어드벤처 게임을 완성한다.  
점프, 공격, 랜덤 보상, 보스 등장, 최고 점수 저장을 포함한다.

## 화면 구성

- 중앙: 작은 맵과 플레이어
- 왼쪽 상단: 점수, 최고 점수
- 오른쪽 상단: 현재 목표
- 하단: 대사, 전투 메시지, 오류 안내

## 기본 조작

| 키 | 동작 |
|---|---|
| 방향키 | 이동 |
| 스페이스 | 점프 |
| A | 공격 |
| E | 상자 열기 |
| R | 다시 시작 |

## 시즌 4에서 배울 감각

- 함수는 게임 기능 버튼이다.
- 매개변수는 함수에 넣는 재료다.
- `return`은 함수가 돌려주는 결과다.
- 랜덤은 게임에 두근거림을 만든다.
- 파일은 점수를 기억하게 만든다.
- 예외 처리는 실수를 만나도 게임이 멈추지 않게 만든다.

## `upgrade_zone.py` 예상 구조

```python
def jump():
    show_message("점프!")

def attack(power):
    damage = power * 2
    return damage

treasure_items = ["동전", "보석", "황금열쇠"]
```

## 챕터별 업그레이드

| 챕터 | 업그레이드 | 아이가 바꾸는 부분 | 결과 |
|---:|---|---|---|
| 37 | 점프 버튼 | `def jump():` | 점프 기능 실행 |
| 38 | 인사 버튼 | 함수 호출 | 버튼처럼 함수 실행 |
| 39 | 힘을 넣는 공격 | 매개변수 | 공격력에 따라 데미지 변경 |
| 40 | 결과 돌려주기 | `return` | 계산 결과를 점수에 사용 |
| 41 | 주사위 공격 | `random.randint()` | 매번 다른 데미지 |
| 42 | 랜덤 보물상자 | `random.choice()` | 랜덤 아이템 획득 |
| 43 | 보스 등장 연출 | `time.sleep()` | 잠깐 기다린 뒤 등장 |
| 44 | 점수 저장 | 파일 쓰기 | 최고 점수 저장 |
| 45 | 점수 불러오기 | 파일 읽기 | 이전 점수 표시 |
| 46 | 입력 실수 처리 | `try/except` | 잘못 입력해도 안내 후 계속 |
| 47 | 규칙 연결 | 함수+조건+반복 | 나만의 규칙 3개 선택 |
| 48 | 최종 완성 | 전체 복습 | 나만의 보물 찾기 게임 완성 |

## 시즌 4 완료 결과

아이는 작은 게임을 직접 업그레이드하고 완성했다는 경험을 얻는다.

# 교재와 게임 연결 방식

각 PDF 챕터는 해당 게임의 `upgrade_zone.py` 한 영역과 연결된다.

## PDF에 들어갈 고정 안내

```text
오늘 열 파일
games/season_01_treasure_score/upgrade_zone.py

오늘 바꿀 곳
챕터 3: 주인공 이름 업그레이드
```

## 챕터별 코드 영역 표시 방식

`upgrade_zone.py`에는 모든 챕터 영역을 처음부터 넣되, PDF에서 오늘의 영역만 다룬다.

```python
# [챕터 3] 주인공 이름 업그레이드
hero_name = "번개용사"
```

## 부모용 안전장치

각 게임 폴더에는 원본 업그레이드 파일을 함께 둔다.

```text
upgrade_zone.py
upgrade_zone_original.py
```

아이가 코드를 많이 바꿔서 실행이 어려워지면 `upgrade_zone_original.py`를 복사해 원래 상태로 되돌릴 수 있게 한다.

# 현재 구현 상태

- 시즌 1 보물 점수 게임 구현 완료
- 시즌 2 던전 선택 게임 구현 완료
- 시즌 3 몬스터 배틀 게임 구현 완료
- 시즌 4 미니 어드벤처 게임 구현 완료
- 구현 위치:
  - `games/season_01_treasure_score/`
  - `games/season_02_dungeon_choice/`
  - `games/season_03_monster_battle/`
  - `games/season_04_mini_adventure/`
- 구현 방식: `tkinter` 기반 2D 화면 게임
- 외부 패키지: 없음
- 실행 파일: `main.py`
- 아이 수정 파일: `upgrade_zone.py`
- 원본 백업 파일: `upgrade_zone_original.py`
- 검증 명령: `python .\main.py --check`
