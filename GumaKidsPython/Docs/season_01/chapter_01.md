# 챕터 1. 게임 화면에 인사하기

오늘은 게임을 처음 켰을 때 나오는 말을 바꿔 봅니다.

## 시작 이야기

아직 배운 코드가 적어도 괜찮아요.
오늘은 파이썬에게 "이 말을 보여줘"라고 부탁하는 첫날입니다.

## 오늘의 업그레이드

오른쪽 파이썬 화면에서 아래 부분을 찾아요.

```python
start_message = "모험 시작!"
```

따옴표 안의 말을 내가 원하는 말로 바꿔 봅니다.

```python
start_message = "보물 찾으러 출발!"
```

## 파이썬 개념

파이썬은 값을 종류별로 기억합니다.
값의 종류를 **자료형**이라고 부릅니다.

`"모험 시작!"`처럼 따옴표 안에 있는 글자는 **문자열**입니다.
파이썬 이름으로는 **str**이라고 합니다.

`10`처럼 따옴표가 없는 숫자는 계산할 수 있는 **숫자 자료형**입니다.
파이썬 이름으로는 **int**라고 합니다.

## Play 해보기

1. 오른쪽 코드에서 문장을 바꿉니다.
2. 위쪽의 `Play` 버튼을 누릅니다.
3. 왼쪽 아래 게임화면의 첫 메시지가 바뀌었는지 봅니다.

## 미션

게임 시작 때 나오는 말을 3가지로 바꿔 보세요.

- "모험 시작!"
- "보물 찾으러 출발!"
- "나는 오늘 용사다!"

## 퀴즈

파이썬에서 글자를 기억하는 자료형 이름은 무엇일까요?

1. 문자열 `str`
2. 숫자 `int`
3. 방향키 `key`

## 정답과 해설

정답은 1번, 문자열 `str`입니다.

자료형은 값의 종류를 말합니다.
따옴표 안에 있는 글자는 문자열이고, 파이썬 이름은 `str`입니다.
따옴표가 없는 `10` 같은 수는 숫자 `int`로 기억합니다.
