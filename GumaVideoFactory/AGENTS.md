# GumaVideoFactory 제작 규칙

- 매일 한국시간 09시 테크·15시 음식·21시 생활용품을 각 1개 제작·비공개 업로드한다. 전체 이력 동일 제품과 최근 7일 업로드의 유사 주제·불편 해결 소재를 제외한다.
- 조사·컷씬은 GPT-6 Astra가 직접 수행한다. Gemini 기획·이미지 생성은 호출하지 않는다. 실제 실행 모델이 다르면 Astra로 변경을 요청하고 산출 모델을 허위 기록하지 않는다.
- 공식 영상 또는 이미지가 있는 최신 트렌드 아이템을 선택한다. 쿠팡 파트너스의 동일 모델·옵션·공식 판매처·로켓배송·실제 발급 링크를 확보한 뒤 컷씬을 만든다. 확인 불가 상품은 제외한다.
- 6~8컷: 필요성 제기 → 제품이 솔루션임을 인지 → 근거 있는 인기/관심 이유 → 핵심·추가 기능 소개 → 채널 프로필 상품 링크 안내. 인기 근거가 없으면 인기라고 단정하지 않는다. 쇼츠 설명·댓글 링크가 클릭된다고 안내하지 않는다.
- 3D 모델 기능은 제거한다. 제품 외형 정확성이 우선이다. 공식 테크 기술·실제 음식·제품 컷은 원본을 보존하고, 재제작이 적합한 생활 문제·후킹 컷만 Veo로 생성한다. 임의 내부 구조·제품 형상·먹어본 경험을 만들지 않는다.
- 원본 음성은 제거하고 모든 영상에 ko-KR-SunHiNeural 음성을 사용한다. 완성 영상의 음성·화면·대사·자료 일치를 직접 검수한다.
- 사용자는 자동 영상 제작과 YouTube 비공개 업로드를 승인했다. @GumaShop86 채널과 중복을 확인한 후 computer-use로 비공개 업로드하고 URL·가시성·파일 해시를 기록한다. 공개 전환은 해당 영상 버전의 사용자 승인 후에만 수행한다.
- 인앱 브라우저 우선, 필요시 Chrome. 로그인 만료·본인인증은 사용자에게 요청하며 연결 불가와 구분한다. 인증 우회·쿠키 추출은 금지한다. 같은 차단은 반복 알리지 않는다. 작업용으로 새로 연 탭은 작업 후 닫고, 기존 사용자 탭과 인증 대기 탭만 유지한다.
- FIFO 큐, 새 버전, 기존 결과·이력 보존. 중단된 유료 요청은 자동 재시도하지 않는다. 기존 3D 파일은 보관만 하며 신규 작업에 사용하지 않는다.
- 피드백은 공통 코드·production_rules.json revision·검증에 반영한다. 관련 MD는 낡은 내용을 교체·통합해 전체 분량을 늘리지 않는다.
