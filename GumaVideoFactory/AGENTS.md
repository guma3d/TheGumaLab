# GumaVideoFactory 작업 지침

- 제작 기준의 단일 문서는 [RESEARCH.md](RESEARCH.md)다. 공통 → 해당 카테고리 → 제작 전후 검수 순으로 적용한다. 실행·배포는 [README.md](README.md), 저장소 작업은 상위 AGENTS.md를 따른다.
- Food·Tech·Living은 기획 전담, Main은 제작·검수·웹 버전 관리·요청된 게시 전담이다. 카테고리별 콘티 버전의 사용자 제작 승인과 Main에서의 영상 버전 공개 승인을 분리한다. 세션 주소·인계 규칙은 README를 따른다. 승인 없는 예약 제작은 진행하지 않는다. 원본·수정 버전·최종본은 프로젝트 storage에 로컬 보존하고 웹에서 관리·링크를 알린다. 최종본도 자동 업로드하지 않으며 정확한 버전의 사용자 업로드 요청이 있을 때만 YouTube에 올린다. 공개 승인은 별개다.
- GPT-6 Astra가 조사·콘티를 직접 작성한다. 실제 모델이 다르면 변경을 요청하며 산출 모델을 허위 기록하지 않는다. Gemini 기획·신규 3D 모델은 사용하지 않는다.
- FIFO와 새 버전으로 작업하며 기존 원본·출처·검수 해시·날짜별 목록·history를 보존한다. 웹 피드백은 아이템·버전·CUT 번호로 반영한다. 실제 Studio 채널·가시성·URL 확인 없이 업로드 완료를 기록하지 않는다.
- 인앱 브라우저 우선, 필요시 Chrome. 로그인·본인인증 필요시 요청하며 연결 장애와 구분한다. 인증 우회·쿠키 추출 금지. 작업용 탭은 종료하고 사용자 탭은 보존한다. 비밀값은 출력·커밋하지 않는다.
- 사용자의 모든 피드백은 즉시 공통 또는 해당 카테고리 범위를 명시해 관련 MD·production_rules.json·실행 로직에 함께 반영한다. 유효하지 않은 규칙은 제거·교체하고 중복은 합쳐 현재 지침만 유지한다. 버전별 과거 제작·검수 기록은 변경하지 않는다. 의미 있는 완료·실패·필요 조치만 알린다.
