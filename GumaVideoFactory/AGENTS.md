# GumaVideoFactory 작업 지침

- 제작 기준의 단일 문서는 [RESEARCH.md](RESEARCH.md)다. 공통 → 해당 카테고리 → 제작 전후 검수 순으로 적용한다. 실행·배포는 [README.md](README.md), 저장소 작업은 상위 AGENTS.md를 따른다.
- 승인한 영상의 원본·수정 버전·최종본은 프로젝트 storage에 로컬 보존하고 웹서비스에서 버전별 관리·검토 링크를 알린다. 최종본도 자동 업로드하지 않는다. 정확한 버전의 사용자 업로드 요청이 있을 때만 YouTube에 올리며 공개 승인은 별개다.
- GPT-6 Astra가 조사·콘티를 직접 작성한다. 실제 모델이 다르면 변경을 요청하며 산출 모델을 허위 기록하지 않는다. Gemini 기획·신규 3D 모델은 사용하지 않는다.
- 제품 실물·기능·출처·쿠팡 동일 옵션·공식 판매처·로켓배송·발급 파트너스 링크를 확인한다. 자료 재사용 가정은 사용권 확보 증거로 기록하지 않는다. 없는 성능·인기·가격·시식 경험을 만들지 않는다.
- 전 카테고리 공통: 메이플스토리 Bold·외곽선·배경 박스 없음. 영상에 반복 AI·쿠팡 파트너스 문구를 넣지 않는다. [광고]는 유지하고 고지는 설명·링크·YouTube AI 설정에서 처리한다.
- 제작 전과 제작 후 총 2회의 검수를 필수로 수행한다. 전체 컷의 스타일 일치, 동일·유사 이미지 중복 없음, 강한 첫 컷 후킹과 근거, 대사-화면 일치를 검토한다. 기술 검사만으로 시각 검수를 대체하지 않는다.
- 음식 생성은 Flow 크레딧으로 진행하고 Veo API로 대체하지 않는다. 단순 색보정·편집은 로컬 처리하고 재사용 가능한 음성·원본은 유지한다. 유료 요청 실패는 맹목적으로 재시도하지 않는다.
- FIFO와 새 버전으로 작업하며 기존 원본·출처·검수 해시·날짜별 목록·history를 보존한다. 웹 피드백은 아이템·버전·CUT 번호로 반영한다. 실제 Studio 채널·가시성·URL 확인 없이 업로드 완료를 기록하지 않는다.
- 인앱 브라우저 우선, 필요시 Chrome. 로그인·본인인증 필요시 요청하며 연결 장애와 구분한다. 인증 우회·쿠키 추출 금지. 작업용 탭은 종료하고 사용자 탭은 보존한다. 비밀값은 출력·커밋하지 않는다.
- 피드백은 공통 또는 해당 카테고리 범위를 명시해 문서·production_rules.json·관련 로직에 반영한다. 낡은 규칙을 교체하고 중복을 합쳐 MD 전체 분량을 늘리지 않는다. 의미 있는 완료·실패·필요 조치만 알린다.
