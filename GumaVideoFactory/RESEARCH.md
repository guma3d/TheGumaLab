# 쇼핑쇼츠 제작 기준

## 1. 전체 공통 지침

### 운영·아이템 선정
- 대상은 20~40대. 09시 테크·15시 푸드·21시 생활 각 1편은 목표 일정이다. 카테고리 세션의 사용자 승인 콘티만 Main이 제작·웹 버전 저장하며 미승인 건은 대기한다.
- 최신 트렌드를 실제 검색하고 제조사 원문·게시일·공식 영상 또는 이미지를 확인한다. 최근 7일 근거 우선, 최대 30일 범위와 날짜를 명시한다. 전체 제품 이력과 최근 7일 Studio(비공개 포함)를 확인해 동일 제품·유사 주제·불편 해결 소재를 피한다. 사용자 재편집은 새 추천과 구분한다.
- 쿠팡 동일 모델·옵션·공식 판매처·로켓배송·실제 발급 파트너스 링크를 확보한다. 판매자로켓·직구로 대체하지 않는다. 참고 자료와 구매 링크를 구분하고 게시 전 판매 상태를 재확인한다.
- 제품·음식 외형과 기능은 실제 근거에 맞춘다. 임의 구조·성능·맛·사용 경험을 만들지 않는다. 핵심 기능과 추가 기능 2개 이상을 확인한다. Gemini 기획과 신규 3D 모델 단계는 사용하지 않는다.

### 첫 컷 후킹·대본
- 첫 장면에서 관심을 끄는 강한 후킹을 보여주고 말한다. 평범한 제품 소개나 막연한 불편 질문으로 시작하지 않는다. 검증된 후기·관심 수치, 현재 유행과 실생활의 연결, 구체적인 필요·궁금증을 활용한다.
- 후기·관심 수치는 집계 범위와 확인일을 기록하고 누적 수치를 최근 급증으로 표현하지 않는다. 유행·상품·캐릭터를 확인하고 타깃은 성인으로 유지한다.
- 6~8컷: 강한 후킹과 필요성 → 제품이 해결책임을 인지 → 근거 있는 관심 이유 → 핵심·추가 특징 → CTA. 첫 컷은 짧고 즉시 이해되게 하며 각 대사는 실제 화면의 행동·내용과 맞춘다.
- 마지막 대사·자막: “영상 속 제품 정보는 고정댓글이나 채널 프로필에서 확인하세요.” 쇼츠 댓글·설명 URL의 클릭 또는 모바일 복사를 보장하지 않는다.

### 화면·자막·음성
- 모든 카테고리의 자막은 메이플스토리 Bold(Maplestory), 배경 박스 없이 외곽선으로 가독성을 확보한다. 색·크기·위치 체계는 영상 내 전 컷에서 통일하며 제품을 가리지 않는다. 왼쪽 위 브랜딩은 제거한다.
- 영상에 AI 이미지·영상 안내와 쿠팡 파트너스 수수료 문구를 반복 삽입하지 않는다. 오른쪽 위 [광고]는 유지한다. 수수료는 설명 첫머리·상품 링크 주변, AI 사용은 YouTube 설정·설명에서 고지한다. 별도 표시가 필요한 가상인물 추천 장면은 표시하거나 사용하지 않는다.
- 영상 전체의 색감·밝기·대비·조명·질감·자막·음성 스타일을 일관되게 유지한다. 첫 기준 컷과 나머지 컷을 비교한다. 밝은 확산 자연광·저대비를 기본으로 하며 과한 명암·인위적 연출을 피한다.
- 동일하거나 시각적으로 겹치는 이미지를 여러 컷에 재사용하지 않는다. 크롭·줌·좌우 반전만 바꾼 같은 화면도 중복이다. 동일 원본 영상의 서로 다른 구간은 소재·행동·구도가 실질적으로 다를 때만 사용한다.
- 1080×1920·30fps 세로 화면, 검은 여백 금지. 원본색 배경 또는 검수한 크롭을 사용한다. 원본 짧은 변 영상 1080px·이미지 720px 이상, 확대 1.5배 이하; 업스케일을 원본 고해상도로 가장하지 않는다.
- 정지 이미지는 미세한 떨림 없이 고정하고 0.2초 전환은 대사 끝을 자르지 않는다. 모든 신규 영상은 Food에서 승인한 Zephyr 여성 목소리와 밝고 다정한 자연스러운 빠른 말투로 통일한다. 과거 버전의 음성 기록은 보존하며 새 음성 제작에 카테고리별 다른 목소리를 쓰지 않는다.
- 새 영상마다 검증된 5곡(Life of Riley, Carefree, Monkeys Spinning Monkeys, Wallpaper, Fluffing a Duck)에서 무작위로 1곡을 선택하고 버전에 저장한다. 재시도 때는 같은 곡을 유지한다. 실제 사용 구간을 -25 LUFS로 측정·정규화한 고정 볼륨으로 믹스하며 대사에 따른 ducking·sidechain·자동 감쇠와 페이드는 적용하지 않는다. 곡 고유의 강약은 보존한다. 대사는 -16 LUFS를 목표로 하되 고정 게인으로 피크 여유를 확보하고 음악보다 최소 6 LU 크게 유지한다. 음악의 존재감·명료도는 청취로 확인하며 기술 수치만으로 들었다고 기록하지 않는다. 음성 전용 원본에서 1회 믹스하고 음악 수정 시 영상 스트림은 재압축하지 않는다. 소스 해시·고정 게인·측정 음량·클리핑·CC BY 4.0 크레딧을 기록한다.

### 제작 전·후 2회 검수

#### 1차: 영상 제작 전
콘티와 전 컷 원본을 직접 확인한다. 강한 첫 컷 후킹·근거, 전체 스타일의 일관성, 동일·유사 이미지 중복 없음, 대사-행동 일치, 실물 정확성·해상도·세로 구도·음성 분량·타깃을 검수한다. 미달 컷은 제작 전에 교체하고 결과를 기록한다.

#### 2차: 영상 제작 후
완성본 전체 흐름과 모든 컷·전환을 검수한다. 1차 항목에 더해 색감·밝기 변화, 자막 폰트·외곽선·배경 박스 없음, 불필요한 고지 자막 없음, [광고], 떨림·여백·음량·발음·템포를 확인한다. 미달은 새 버전으로 수정 후 재검수한다. 청취 불가 시 들었다고 기록하지 않고 웹 음성 리뷰 대기로 남긴다. 기술 검사 통과만으로 감독 검수를 완료 처리하지 않는다.

## 2. 신형 테크 지침
- 검증한 쿠팡 옵션 가격 50만원 이하. 새 기능·기술이 생활에서 무엇을 바꾸는지 중심으로 구성한다.
- 생활 문제 → 기술 원리·해결 과정 → 핵심 기능과 추가 기능 2개 이상 → 사용 조건·한계. 정확한 공식 기술 자료와 제품 디테일로 전문성을 보여준다.
- 깔끔한 기술 설명, 민트 강조색, 공통 Zephyr 음성. 밝은 공통 화면 기준을 유지한다. 실제 내부 형상을 확보하지 못하면 명확한 원리 표현만 사용하며 실물처럼 꾸미지 않는다.

## 3. 트렌드 푸드 지침
- Food 검색은 최근 뉴스·방송 화제(공식 프로그램/회차/방영일)·해외 현지 음식 유행(국가/원문/사건일)·쇼핑몰 판매/품절·레시피 재료의 4경로로 진행한다. 최근 7일 우선·최대 30일, 기사 게시일과 사건일을 구분한다. `recommendation_import.py --food-search-plan`으로 날짜별 검색어를 얻고 실제 검색·원문을 확인한다. 신규 추천의 food_trend에 경로·국가·사건일·출처와 완제품/관련 제품/조리 재료 연결 근거를 저장한다. 방송 노출만으로 인기라 하지 않고 품절은 판매처·옵션·확인시각·별도 출처로 검증한다. 단일 품절을 대란으로 확대하지 않는다. 로켓배송 완제품 또는 검증한 레시피 핵심 재료로 연결하며 동일 제품·맛·유행을 꾸미지 않는다.
- 후킹 → 재료·질감 → 개봉·준비 → 적합한 보관·즐기기 → CTA. 매 컷 소재·행동·구도를 바꾸고 단면은 최대 1컷만 사용한다. 제품에 맞지 않는 딸기·냉동·조리 장면은 강제하지 않는다.
- 밝은 저대비 실사 질감·핑크 강조·Zephyr 여성 음성. 음식별 전후 프레임으로 중간톤 온기·재료색을 조정하고 전 컷을 맞춘다. 실물색·피부·흰 접시·포장은 보호하고 과포화·광택·과한 대비를 피한다. 고정 강도 필터를 강제하지 않으며 자막은 후보정 후 합성한다. 불연속 색상 마스크를 피하고 모든 컷의 움직임·전환에서 노이즈·깜빡임·잔상을 검수한다.
- 해동은 실제 안내 방식, 보관은 해당 제품·포장을 넣는 장면을 쓴다. 얼음팩 등 무관한 화면으로 대신하지 않는다. 공식 실물은 보존하며 생성 포장은 실물과 대조한다.
- [승인 콘티](docs/references/food-storyboard-approved-v1.png)와 딸기 크림떡 Video v0010을 현재 기준작으로 삼는다. 사용자 평가: 목표 수준 약 80%, 개선 중. 구성을 참고하되 다른 식품에 복제하지 않는다. 음식 생성은 Flow 크레딧, Veo API 대체 금지.

## 4. 생활용품 지침
- Living은 동일 제품의 고화질 리소스를 실제 확보할 수 있음을 검증한 제품만 추천한다. 사전 일괄 다운로드를 생략할 수 있다는 뜻이지 자료 존재·재생 확인만으로 추천해도 된다는 뜻이 아니다. 출처·동일 모델/옵션 판단·확보 경로와 검증 근거·해상도·육안 화질을 기록한다. 짧은 변 720px 이상, 1080p 우선이며 실제 작동이 핵심인 제품은 선명한 실사용 영상과 사용할 구간까지 확인한다. 다운로드 실패 후 다른 검증된 확보 경로가 없거나 저화질·필수 작동 장면 미확인인 후보는 추천에서 제외한다. 자료 확보 가능성과 재사용 허가는 구분한다. 제작 준비·웹 제작 등록에는 기존 readiness 원본 확보·검수를 적용한다.
- 아이템 탐색은 판매·리뷰 검증과 최근 뉴스 화제성 두 경로를 사용한다. 공개 구매 지표의 원문·기간·집계 범위·확인 시각, 상품평 수·평점·옵션 합산 여부를 기록한다. 판매량 미공개는 미공개로 남기며 리뷰 수로 판매량을 추정하지 않는다. 리뷰 500개·평점 4.3 이상을 초기 탐색 우선값으로 삼되 절대 기준으로 강제하지 않고 카테고리 내 비교·최근 후기·낮은 평점의 반복 불만을 함께 검토한다.
- 뉴스는 최근 7일 우선·최대 30일의 원문 게시일과 사건일을 확인한다. 보도자료 재배포를 여러 독립 근거로 세지 않으며 관련 품목의 유행을 특정 제품의 판매 급증으로 바꾸지 않는다. 리뷰가 적은 신제품도 뉴스 근거로 검토하되 판매 검증 부족을 명시한다. 생활 불편·계절성·디자인·선명한 동일 제품 실제 시연 확보 가능성과 중복 여부를 종합해 추천한다. 후보 조사와 제작 승인을 구분한다.
- `recommendation_import.py --living-search-plan`으로 조사 계획을 확인한다. 신규 Living 등록은 `living_evidence`가 필요하며 commerce는 최근 확인한 판매/리뷰 지표, news는 최근 사건일·게시일을 검증한다. 누적 리뷰 상품 페이지에 가짜 게시일을 붙이지 않는다.
- 실제 작동 후보는 동일 모델 확인과 함께 접촉 부위·작동 전후 표면·제거 결과가 구간 안에서 얼마나 보이는지 기록한다. 단순 접촉·개봉 장면을 제거 효과의 근거로 대체하지 않는다. 사용자가 후보 선택을 요청하면 비교 후보를 먼저 제시하고 선택 후 소스를 교체한다. 효과를 생성하거나 서로 다른 원단을 전후처럼 연결하지 않는다.
- 움직이는 실사용 컷의 길이 부족을 마지막 프레임 정지로 채우지 않는다. 전환 직전까지 원본 움직임이 이어지도록 실제 구간 또는 인접 컷 타이밍을 조정하고, 음성의 무음 여백만 다듬어 대사 끝을 보존한다. 제작 전 사용 구간 길이와 음성 길이를 대조하고 제작 후 모든 전환 앞뒤를 연속 프레임·재생으로 확인한다. 의도된 공식 정지 사진은 별도다.
- 모든 이미지·영상은 항상 실제 해상도와 육안 선명도를 함께 확인한다. 원본 100%와 최종 세로 구도에서 흐림·노이즈·압축 뭉개짐을 검수하며, 픽셀 수가 높아도 흐릿하면 제외한다. 영상은 사용할 실제 작동 구간을 직접 재생해 제품 동작·접촉 부위·작동 결과가 깨끗하게 보이는지 반드시 확인하고 구간·해상도·검수 결과를 기록한다. 썸네일·개봉 장면만 보고 통과시키지 않는다. 사용자 기준: 테스트 image_04.webp는 화질 미달. 최신 선호 사례는 2026-10-06 선택한 미지아2 후보1 흰 원단 근접 시연(rednote-working-720.mp4)이다. 선택은 해당 화면의 수용 근거이며 모델번호 라벨 확인이나 정량적 전후 성능 검증을 뜻하지 않는다. 소재가 바뀌면 화면 제목도 실제 소재에 맞춘다.
- 모든 Living 추천은 샤오홍슈/rednote 검색을 필수로 거친다. 브랜드·모델의 중국어/영문 검색어·검색/게시물 출처·동일 제품 영상 유무·화질·확보 가능 여부를 기록하고, 검색 결과 수와 실제 검증된 사용 가능 영상 수를 구분한다. 다른 사이트 자료만 확인한 결과로 대체하지 않는다. 콘티에 맞는 다양한 실제 사용 영상·이미지를 확보할 수 있는 제품을 우선하며 쿠팡파트너스 상품과 브랜드·모델·옵션·외형·구조가 동일함을 확인한다. 유사 제품으로 대체하지 않는다. 신규 등록에는 living_evidence.xiaohongshu_searches가 필요하다.
- 영상 원본은 짧은 변 1080px 이상을 우선하며, 없으면 선명한 720px 이상도 허용한다(Living 예외). 실제 해상도를 기록하고 세로 편집 후 선명도·공통 확대 기준을 검수한다. 중국어가 많은 자료는 제외하고, 적은 문구만 크롭·마스킹·배경 복원으로 제거한다. 제품·손에 겹친 글자의 제거 흔적은 검수하고 미달이면 교체한다. 제품 자체 표기를 지워 실물 외형을 바꾸지 않는다.
- 인물 등장 자료도 사용할 수 있으나 제품 단독·손 중심 실사용 장면을 우선한다. 컷별 원본 링크·사용 가능 근거·동일 제품 판단 근거·사용 구간·중국어 제거 방법을 제작 명세에 기록해 Main에 인계한다.
- 생활 불편·계절 수요·신기한 쓰임·검증된 신제품에서 아이템을 선정한다. 커터·그릴·주방타월·정전기 제거기 등은 예시이며 현재 인기는 따로 확인한다.
- 강한 필요·관심 후킹 → 실제 사용 방법 → 편리한 이유 → 추가 특징·한계. 같은 제품 정면 사진을 반복하지 말고 준비·사용·정리 등 구체적인 행동을 보여준다.
- 밝은 실사용 장면, 파랑 강조색, 공통 Zephyr 음성. 임의의 극적인 전후 비교나 검증되지 않은 무연·완벽 세척·성능 보장은 금지한다.

## 5. 실행·보존
`docker exec GumaVideoFactory_app python shopping_package.py`를 사용한다.
1. `build 후보.json --file 콘티.json`: 검증한 Recommendation과 Astra Board로 새 Preview 생성. 원본·출처·컷 번호·대사·수정 근거 보존.
2. `seal ID --version N --file 검수.json`: 1차 검수의 reviewed_by, passed, board_sha256, 전 scenes 검수, preflight 전 항목, unresolved_issues=[] 기록. 스타일 일관성·중복·후킹 근거를 notes에도 명시한다.
3. Main만 승인된 콘티 버전·해시를 확인하고 `enqueue ID --version N`: 검수한 소스와 공통 Zephyr 음성으로 제작. 재생성은 새 버전, 변경 없는 음성·소스 재사용. 음식은 Flow 결과 파일을 먼저 등록한다.
4. 2차 검수 후 `review`에 실제 청취·시각 결과와 file_sha256 기록. 청취 불가 시 `review_web`와 audio_review=user_review_on_web 사용. 두 검수의 관찰 근거를 남긴다.
5. 원본·수정 버전·최종본을 프로젝트 storage에 로컬 저장하고 웹에서 버전별 관리·검토 링크를 알린다. 최종본도 자동 업로드 금지. 사용자가 해당 버전 업로드를 요청하면 `authorize_upload` → `claim` 후 Studio 채널·기존 업로드를 확인하고 실제 URL·가시성을 기록한다. 공개는 별도 정확한 버전 승인 후만 진행한다.
6. 새 추천은 recommendation_import.py로 날짜·시간별 history 보존. 수정은 기존 아이템 아래 새 버전으로 저장하고 API 최신 상태를 확인한다. edits의 아이템·CUT 번호 피드백 반영 후 edit-done 기록. 브라우저 작업 탭은 닫는다.
