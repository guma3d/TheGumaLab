# 쇼핑쇼츠 제작 기준

## 1. 전체 공통 지침

### 운영·아이템 선정
- 대상은 20~40대. 한국시간 09시 테크·15시 푸드·21시 생활용품 각 1편, 하루 총 3편을 @GumaShop86에 비공개 업로드한다.
- 최신 트렌드를 실제 검색하고 제조사 원문·게시일·공식 영상 또는 이미지를 확인한다. 최근 7일 근거 우선, 최대 30일 범위와 날짜를 명시한다. 전체 제품 이력과 최근 7일 Studio(비공개 포함)를 확인해 동일 제품·유사 주제·불편 해결 소재를 피한다. 사용자 재편집은 새 추천과 구분한다.
- 쿠팡 동일 모델·옵션·공식 판매처·로켓배송·실제 발급 파트너스 링크를 확보한다. 판매자로켓·직구로 대체하지 않는다. 참고 자료와 구매 링크를 구분하고 게시 전 판매 상태를 재확인한다.
- 제품·음식 외형과 기능은 실제 근거에 맞춘다. 임의 구조·성능·맛·사용 경험을 만들지 않는다. 핵심 기능과 추가 기능 2개 이상을 확인한다. Gemini 기획과 신규 3D 모델 단계는 사용하지 않는다.

### 첫 컷 후킹·대본
- 첫 장면에서 관심을 끄는 강한 후킹을 보여주고 말한다. 평범한 제품 소개나 막연한 불편 질문으로 시작하지 않는다. 검증된 후기·관심 수치, 현재 유행과 실생활의 연결, 구체적인 필요·궁금증을 활용한다.
- 예: “공식몰 후기 5만 건을 넘긴 딸기 크림떡, 속을 볼까요?” 수치의 집계 범위와 확인일을 기록한다. 누적 후기를 최근 급증한 것처럼 표현하지 않는다.
- 예: “포켓몬카드에 빠진 아이에게, 오늘은 포켓몬 돈까스 어때요?” 유행 여부와 실제 판매 상품·캐릭터를 확인한 경우에만 사용한다. 구매 타깃은 부모 등 성인이며 예시를 모든 제품에 강제하지 않는다.
- 6~8컷: 강한 후킹과 필요성 → 제품이 해결책임을 인지 → 근거 있는 관심 이유 → 핵심·추가 특징 → CTA. 첫 컷은 짧고 즉시 이해되게 하며 각 대사는 실제 화면의 행동·내용과 맞춘다.
- 마지막 대사·자막: “영상 속 제품 정보는 고정댓글이나 채널 프로필에서 확인하세요.” 쇼츠 댓글·설명 URL의 클릭 또는 모바일 복사를 보장하지 않는다.

### 화면·자막·음성
- 모든 카테고리의 자막은 메이플스토리 Bold(Maplestory), 배경 박스 없이 외곽선으로 가독성을 확보한다. 색·크기·위치 체계는 영상 내 전 컷에서 통일하며 제품을 가리지 않는다. 왼쪽 위 브랜딩은 제거한다.
- 영상에 AI 이미지·영상 안내와 쿠팡 파트너스 수수료 문구를 반복 삽입하지 않는다. 오른쪽 위 [광고]는 유지한다. 수수료는 설명 첫머리·상품 링크 주변, AI 사용은 YouTube 설정·설명에서 고지한다. 별도 표시가 필요한 가상인물 추천 장면은 표시하거나 사용하지 않는다.
- 영상 전체의 색감·밝기·대비·조명·질감·자막·음성 스타일을 일관되게 유지한다. 첫 기준 컷과 나머지 컷을 비교한다. 밝은 확산 자연광·저대비를 기본으로 하며 과한 명암·인위적 연출을 피한다.
- 동일하거나 시각적으로 겹치는 이미지를 여러 컷에 재사용하지 않는다. 크롭·줌·좌우 반전만 바꾼 같은 화면도 중복이다. 동일 원본 영상의 서로 다른 구간은 소재·행동·구도가 실질적으로 다를 때만 사용한다.
- 1080×1920·30fps 세로 화면, 검은 여백 금지. 원본색 배경 또는 검수한 크롭을 사용한다. 원본 짧은 변 영상 1080px·이미지 720px 이상, 확대 1.5배 이하; 업스케일을 원본 고해상도로 가장하지 않는다.
- 정지 이미지는 미세한 떨림 없이 고정한다. 0.2초 부드러운 전환은 대사 끝을 자르지 않는다. 원본 음성은 제거하고 지정 음성을 밝고 다정하고 자연스럽게 빠른 말투로 유지한다. 모든 카테고리는 콘티 분위기에 맞는 검증 BGM 5곡 중 bgm_track을 지정한다(카테고리 고정 금지). 소스·크레딧 없으면 완료 금지. 대사 우선 음량·ducking·시작/끝 fade·클리핑을 검수하고 CC BY 4.0 크레딧·편집 내역을 설명에 자동 추가한다. 음악만 수정할 때 영상 스트림은 재압축 없이 보존한다.

### 제작 전·후 2회 검수

#### 1차: 영상 제작 전
콘티와 전 컷 원본을 직접 확인한다. 강한 첫 컷 후킹·근거, 전체 스타일의 일관성, 동일·유사 이미지 중복 없음, 대사-행동 일치, 실물 정확성·해상도·세로 구도·음성 분량·타깃을 검수한다. 미달 컷은 제작 전에 교체하고 결과를 기록한다.

#### 2차: 영상 제작 후
완성본 전체 흐름과 모든 컷·전환을 검수한다. 1차 항목에 더해 색감·밝기 변화, 자막 폰트·외곽선·배경 박스 없음, 불필요한 고지 자막 없음, [광고], 떨림·여백·음량·발음·템포를 확인한다. 미달은 새 버전으로 수정 후 재검수한다. 청취 불가 시 들었다고 기록하지 않고 비공개 음성 리뷰 대기로 남긴다. 기술 검사 통과만으로 감독 검수를 완료 처리하지 않는다.

## 2. 신형 테크 지침
- 검증한 쿠팡 옵션 가격 50만원 이하. 새 기능·기술이 생활에서 무엇을 바꾸는지 중심으로 구성한다.
- 생활 문제 → 기술 원리·해결 과정 → 핵심 기능과 추가 기능 2개 이상 → 사용 조건·한계. 정확한 공식 기술 자료와 제품 디테일로 전문성을 보여준다.
- 깔끔한 기술 설명, 민트 강조색, Achird 남성 음성. 밝은 공통 화면 기준을 유지한다. 실제 내부 형상을 확보하지 못하면 명확한 원리 표현만 사용하며 실물처럼 꾸미지 않는다.

## 3. 트렌드 푸드 지침
- 최근 유행하는 음식에서 쿠팡 완제품 또는 재료·조리법으로 자연스럽게 연결한다. 맛이 동일하다고 보장하거나 먹어본 것처럼 말하지 않는다.
- 후킹 → 재료·질감 → 개봉·준비 → 적합한 보관·즐기기 → CTA. 매 컷 소재·행동·구도를 바꾸고 단면은 최대 1컷만 사용한다. 제품에 맞지 않는 딸기·냉동·조리 장면은 강제하지 않는다.
- 밝은 저대비 실사 질감·핑크 강조·Zephyr 여성 음성. 음식별 전후 프레임으로 중간톤 온기·재료색을 조정하고 전 컷을 맞춘다. 실물색·피부·흰 접시·포장은 보호하고 과포화·광택·과한 대비를 피한다. 고정 강도 필터를 강제하지 않으며 자막은 후보정 후 합성한다. 불연속 색상 마스크를 피하고 모든 컷의 움직임·전환에서 노이즈·깜빡임·잔상을 검수한다.
- 해동은 실제 안내 방식, 보관은 해당 제품·포장을 넣는 장면을 쓴다. 얼음팩 등 무관한 화면으로 대신하지 않는다. 공식 실물은 보존하며 생성 포장은 실물과 대조한다.
- [승인 콘티](docs/references/food-storyboard-approved-v1.png)와 딸기 크림떡 Video v0010을 현재 기준작으로 삼는다. 사용자 평가: 목표 수준 약 80%, 개선 중. 구성을 참고하되 다른 식품에 복제하지 않는다. 음식 생성은 Flow 크레딧, Veo API 대체 금지.

## 4. 생활용품 지침
- 생활 불편·계절 수요·신기한 쓰임·검증된 신제품에서 아이템을 선정한다. 커터·그릴·주방타월·정전기 제거기 등은 예시이며 현재 인기는 따로 확인한다.
- 강한 필요·관심 후킹 → 실제 사용 방법 → 편리한 이유 → 추가 특징·한계. 같은 제품 정면 사진을 반복하지 말고 준비·사용·정리 등 구체적인 행동을 보여준다.
- 밝은 실사용 장면, 파랑 강조색, Achird 남성 음성. 임의의 극적인 전후 비교나 검증되지 않은 무연·완벽 세척·성능 보장은 금지한다.

## 5. 실행·보존
`docker exec GumaVideoFactory_app python shopping_package.py`를 사용한다.
1. `build 후보.json --file 콘티.json`: 검증한 Recommendation과 Astra Board로 새 Preview 생성. 원본·출처·컷 번호·대사·수정 근거 보존.
2. `seal ID --version N --file 검수.json`: 1차 검수의 reviewed_by, passed, board_sha256, 전 scenes 검수, preflight 전 항목, unresolved_issues=[] 기록. 스타일 일관성·중복·후킹 근거를 notes에도 명시한다.
3. `enqueue ID --version N`: 검수한 소스와 카테고리 음성으로 제작. 재생성은 새 버전, 변경 없는 음성·소스 재사용. 음식은 Flow 결과 파일을 먼저 등록한다.
4. 2차 검수 후 `review`에 실제 청취·시각 결과와 file_sha256 기록. 청취 불가 시 `review_private`와 audio_review=user_review_on_private_youtube 사용. 두 검수의 관찰 근거를 남긴다.
5. `claim` 후 Studio 채널·기존 업로드 확인, 비공개 업로드. 실제 URL·가시성을 확인한 다음 `private` 기록. 공개는 정확한 버전 승인 후만 진행한다. 비공개 댓글은 pending으로 보관한다.
6. 새 추천은 recommendation_import.py로 날짜·시간별 history 보존. 수정은 기존 아이템 아래 새 버전으로 저장하고 API 최신 상태를 확인한다. edits의 아이템·CUT 번호 피드백 반영 후 edit-done 기록. 브라우저 작업 탭은 닫는다.
