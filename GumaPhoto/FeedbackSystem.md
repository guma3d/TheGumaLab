# GumaPhoto Feedback System (피드백 시스템) 기획안

## 1. 개요 및 목적
현재 GumaPhoto의 AI 얼굴 인식 파이프라인에서 `Unknown People` (미등록 인물)로 분류된 인물들을 손쉽게 식별하고, 시스템에 새로운 가족/지인으로 등록하여 기존의 'Unknown' 데이터들을 일괄적으로 업데이트(재학습 및 인덱싱)하는 워크플로우를 구축합니다.

---

## 2. 사용자 시나리오 (UI/UX 흐름)

1. **진입점 (피드백 버튼)**
   - 메인 웹 UI 화면 상단의 Upload 아이콘 왼쪽에 **"Feedback (피드백/학습)" 버튼**을 추가합니다.
   
2. **미등록 인물 모달 (Clustering View)**
   - 피드백 버튼을 클릭하면 모달 창이 열립니다.
   - DB에 `Unknown People`로 등록된 사진 중, **벡터 유사도가 높은 9장의 사진**을 집중적으로 그룹화하여 보여줍니다.
   - 💡 *(엔지니어 조언)*: 무작위 랜덤보다는 Qdrant DB를 이용해 **'가장 자주 등장하지만 이름이 없는 인물 군집(Top Unknown Cluster)'** 을 기준으로 9장을 뽑아주면, 우선순위가 높은 인물들부터 효과적으로 피드백을 수집할 수 있습니다.
   
3. **인물 식별 및 이름 입력**
   - 모달에서 사용자에게 **"동일한 인물이 등장하는 사진들을 체크하고 해당 인물의 이름을 입력하세요"** 라고 안내합니다.
   - 사용자는 동일 인물이라 판단되는 사진의 체크박스를 선택(활성화)하고, 텍스트 입력창에 인물의 이름이나 별명을 기입합니다.

4. **학습 데이터 복사 (Enroll)**
   - 텍스트 박스에 입력된 이름과 동일한 폴더가 `data/enrolled/` 내부에 이미 있는지 자동 확인합니다.
   - **존재할 경우:** 해당 폴더 안에 선택된 사진 원본들을 복사하여 추가합니다.
   - **존재하지 않을 경우:** 입력된 이름으로 새 디렉토리를 만들어 선택된 사진 원본들을 복사합니다.
   
5. **피드백 리스트 (Queue) 추가**
   - 사용자가 체크한 사진들의 고유 정보(경로나 Qdrant ID 등)가 내부적인 **'피드백 리스트(DB Table 등)'** 에 등록됩니다.

---

## 3. 백엔드 처리 로직 (피드백 시스템 적용 트리거 실행 시)

즉시 재인덱싱을 진행하면 시스템에 병목이 생길 수 있으므로, 사용자가 피드백 리스트를 관리하다가 **"피드백 반영(Re-indexing) 시작" 버튼을 눌렀을 때 일괄 실행**되는 배치를 권장합니다.

1. **새로운 얼굴 데이터 임베딩 업데이트 (필수 반영 사항) 💡**
   - ⚠️ 가장 중요한 단계입니다! 새로운 사진들이 `data/enrolled/` 에 복사되었더라도, 기존의 `known_faces.pkl` 파일(얼굴 특징점 좌표 정보)이 최신화되지 않으면 AI 모델은 새 이름을 알지 못합니다.
   - 따라서 트리거 실행 시, 가장 먼저 **`얼굴 학습 스크립트(enroll_batch.py 등)`를 백그라운드에서 한 번 구동**하여 최신화된 가족 얼굴 특징점 데이터를 메모리에 적재해야 합니다.

2. **재수집 및 피드백 리스트 확장 (Vector Search)**
   - 사용자가 방금 선택하여 큐에 담아둔 "기준 얼굴"들의 특징 벡터 값을 Qdrant DB에서 호출합니다.
   - 현재 `Unknown People` 태그를 보유하고 있는 전체 사진을 대상으로, 기준 얼굴 벡터와 **얼굴 구조 유사도(Cosine Similarity)가 가장 높은 상위 200장의 사진을 검색**해옵니다.
   - 검색된 200장의 사진들을 모두 피드백 리스트(재인덱싱 작업 대상)에 포함시킵니다.

3. **기존 데이터 깔끔한 초기화 (Cleanup)**
   - 피드백 리스트에 포함된 수백 장의 사진들에 대해 찌꺼기가 남지 않도록:
     - 디스크의 기존 `.xmp` 메타데이터 백업 파일들을 제거합니다.
     - SQLite DB (`vectorized_files`)의 기존 "DONE" 상태 정보를 초기화하거나 목록에서 제거합니다.
     - Qdrant 벡터 DB에서도 기존 인물 태깅이 오염되지 않도록 해당 `payload(point_id)`를 우선 Drop 합니다.

4. **선택적 재-인덱싱 (Targeted Vector Indexing)**
   - 로컬의 `vector_indexer.py`가 전체 폴더를 처음부터 도는 것이 아니라, 특정 텍스트 리스트만 넘겨받아 다시 타겟팅 분석하는 옵션(예: `--target-list feedback.json`)을 추가 연동합니다.
   - 새로 학습된 얼굴 인지 AI를 장착한 상태로 대상 사진(200여 장)을 1장씩 다시 분석합니다.
   - 기존의 `Unknown People`이 아닌 **방금 지정한 특정한 가족/지인 이름**으로 얼굴이 성공적으로 새롭게 덮어씌워 색인됩니다!
   - 그 결과, 리스트 내 사진 전부 새로운 XMP 메타데이터와 Qdrant DB 구조 형성이 완료됩니다.

## 4. 핵심 트러블슈팅 및 버그 픽스 역사 (엔지니어 관점)

1. **InsightFace 딥러닝 크롭(Crop) 왜곡 버그 타파:**
   - **이슈:** 초기 피드백 재학습 시, 얼굴 이미지를 자를 때 여백(Margin)을 고작 20%(0.2)만 주는 바람에 인공지능이 얼굴의 목과 어깨 컨텍스트를 상실, 심하게 왜곡된 상태로 학습을 진행해 유클리디안 거리가 떡락하는 현상 발견.
   - **해결:** 재학습 등록(`enroll`) 과정의 여백 비중을 모델 표준 권장치인 **100%(1.0)로 확대**하여 온전한 얼굴과 배경 일부를 함께 담아 왜곡 없는 무결점 재학습 성능 달성. 대신 1.0 범위로 크롭 시 다른 사람의 뺨이 잡힐 것을 대비하여 항상 **'정중앙(Center) 좌표에 가장 근접한(Closest) 얼굴'** 만을 정확히 핀포인트로 사격하는 수학적 방어 모듈 체결 완비!
2. **Qdrant ID 배치(Batch) 순서 미스매치 (치명적 버그 해결):**
   - **이슈:** `Retrieve` 된 사진 200장과 점수(Score) 배열 리스트의 index 뼈대가 안 맞는 싱크가 꼬이는 어레이 미스매치 에러를 발견하여 긴급 수정하였습니다. (딕셔너리 키 ID 기반 맵핑 도입)
3. **'Unknown' 잔류 찌꺼기 추적 버그 및 캐시 동기화:**
   - **이슈:** UI에서 일괄 피드백 유사도를 추천할 때 프론트엔드가 자체적으로 영단어를 잘라먹거나(truncating), `?v=132` 같은 캐시 토큰이 갱신되지 않아 최신 로직을 반영하지 못하던 현상 완벽 타파!
   - `unify_unknowns.py` 등 관리 스크립트 실행 후 `bump_version.py` 를 연동 가동하여 클라이언트 캐시 무효화를 100% 자동 분배 달성!
4. **메타데이터 파고들기 버그 (스코프 섀도잉) 격파:**
   - **이슈:** 비동기 Celery 워커 환경 내에서 피드백 수정 로직(여러 장의 사진 타겟팅)을 구동 시, 내부 메서드 안의 `import json` 섀도잉 현상이 외부 전역 모듈의 속성을 먹어버려 타겟 사진 배열(JSON Array) 파싱이 `JSONDecodeError`를 뱉으며 1장만 처리되는 침묵의 오류(Silent Degradation) 발생.
   - **해결:** 로컬 스코프의 모듈 임포트를 격리/삭제하고 배열 파싱과정의 투명성을 확보하여 N개의 다중 타겟(Batch)을 무결점으로 업데이트 성공!
5. **순수 ExifTool 기반 진실 공급원(Source of Truth) 확립:**
   - **이슈:** 과거에는 장소/날짜 메타데이터를 벡터에 동기화할 때 상위 폴더 이름(`2017-03_위치정보없음`)을 얕게 잘라 추정하는 방식을 썼는데, 피드백 이후 디렉토리가 꼬이면서 데이터 유실을 낳음.
   - **해결:** 폴더 이름을 믿는 대신, 오직 파일 내재 메타데이터(Exif/XMP)만을 읽어오도록 아키텍처를 원천 수정함. 피드백으로 위치/날짜가 교정되면 `MetadataEditor`가 하드코딩하고, Qdrant DB는 무조건 이를 신뢰하도록 연결. 추가적으로 이 변동 사항을 `audit_trace.json` 블랙박스로 100% 영구 기록(Before vs After)하도록 안전망 구축 완료.
