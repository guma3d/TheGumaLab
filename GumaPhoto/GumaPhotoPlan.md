# GumaPhoto 프로젝트 마스터 플랜 (가족 특화 시맨틱 검색 시스템)

이 문서는 GumaPhoto 서비스의 전체 기획과 향후 로드맵을 정의합니다. (수시로 업데이트 됩니다)

## 📌 최종 목표
- 가족 구성원의 얼굴을 학습시키고 모든 사진에서 인물, 표정, 배경(장소, 분위기) 정보를 다각도로 추출하여 벡터 DB에 영구 보존.
- 모바일(스마트폰)에서 무제한 대량의 사진을 즉각적으로 업로드하고, 백그라운드에서 실시간으로 갤러리를 정렬/분석하는 무중단 동기화 서비스 구축.
- 사용자의 자연어(예: "가족들이랑 해변가에서 웃고있는 사진", "아빠가 군복 입은 사진")를 찰떡같이 알아듣는 LLM 기반 사진 검색 엔진 개발.
- 홈서버(FastAPI+Nginx) 위에서 가족 누구나 웹/모바일로 쉽게 접근 가능한 구글 포토(클라우드 갤러리) 수준의 개인화 갤러리 런칭.

---

## ✅ 1단계: 개발 환경 구성 및 홈서버 인프라 구축 (완료)
1. **Docker 기반 환경 세팅**: `docker-compose.yml`을 통해 메인 FastAPI 애플리케이션(`gumaphoto_app`) 및 Qdrant 벡터 DB(`gumaphoto_qdrant`) 구축.
2. **홈서버 연동 지원**: `TheGumaLab` 메인 포털 인덱스에 GumaPhoto 추가 및 Nginx 리버스 프록시(`/GumaPhoto`) 매핑 완료.
3. **코드베이스 클린 아키텍처**: 뼈대 파일 4개만 루트에 남기고 약 50여 개의 진단/테스트 찌꺼기 파일들을 `DebugTool`, `Scripts`, `OneTimeFixes` 구조로 완벽히 분리 정돈 (Zero Clutter).

## ✅ 2단계: 자동 스마트 분류 파이프라인(Organizer) (완료)
1. **시계열 & 메타데이터 구조화**: 기존 뒤섞인 원본 사진들을 `YYYY/YYYY-MM/YYYY-MM-DD_01.jpg` 형식의 규격화된 트리 구조로 자동 재배치. (`organizer_pipeline.py`)
2. **표준 한국어 위치 명칭 강제 (Geocoding)**: OpenStreetMap Nominatim 라이브러리를 통해 추출한 세계 공용 GPS 좌표를 무조건 정식 한국어 포맷(도/특광역시-시/군/구)으로 한글화 변환 반영 (예: Honolulu -> 미국-호놀룰루).
3. **완벽 연속 압축 정렬 (Compress Sequence)**: 확장자 문제로 동일 번호를 부여받거나 중간에 삭제/분리가 발생해도, 빈 번호를 1번부터 차례대로 당겨서 구멍 없이 빽빽하게 (1, 2, 3...) 테트리스 식으로 100% 무결점 정렬 완료.

## ✅ 3단계: 멀티모달(얼굴+배경+사물+서사) 하이브리드 벡터화엔진 (완료)
1. **안면 인식 (InsightFace)**: 최대 수준의 안면 추출 엔진(`buffalo_l`)을 가동하여 사진에 등장한 인물들의 512차원 벡터와 성별/나이 추출.
2. **표정 분석 (HSEmotion)**: PyTorch 초경량 모델로 'Happiness', 'Sadness', 'Contempt' 등 감정 상태 분석.
3. **분위기 분석 (최신 SigLIP)**: `google/siglip` 엔진을 가동하여 피사체/색감 분위기벡터(768차원) 생성.
4. **객체 탐지/묘사 (Florence-2-base)**: 윈도우 한계 극복, MS의 최첨단 VLM으로 영문 문장 캡션 자동 저술 및 OOM(GPU 크러시) 완전 방어(순차 릴레이 로직).
5. **다이나믹 메타-사전 자동 갱신**: 인덱싱 작업(`vector_indexer.py`)이 끝나면 발견된 공식 한국어 장소명 데이터들을 자동 스캔하여, Gemini 자연어 파서에게 먹일 마스터 사전(`available_tags.json`)을 자가 갱신(Self-Healing).

## ✅ 4단계: FastAPI 백엔드 검색 엔진 및 UI/UX 고도화 (완료)
1. **정확 무결성 LLM 서치 시스템**: Gemini가 검색어를 유추(오타 보정)하되, 아예 알래스카 같이 엉뚱한 지역을 강제 변환하는 '할루시네이션(환각)'을 없애기 위해 **마스터 사전에 위치 정보가 없을 시 무조건 빈 칸 반환**을 명령하는 강력한 프롬프트 장착. 
2. **구글 포토 스타일 타임라인 뷰**: 전체 사진을 연도/월별로 부드럽게 감상.
3. **유령 파일(Ghost File) 없는 Hard Delete**: 사용자가 폰에서 사진 삭제(Delete) 버튼을 누를 시 물리적 원본 + XMP + SQLite + Qdrant Point에 이어, 가장 쉽게 놓치는 **WEBP 썸네일 파생 파일까지 완벽하게 소구**하여 하드디스크의 영구적 오염 방지.

## ✅ 5단계: 모바일 실시간 업로드 및 동기화 무중단 파이프라인 (완료)
1. **스마트폰 백그라운드 수신**: `uploads_raw` 임시 폴더에 떨어지자마자, 중복 해시 철통 방어를 거치고 즉각 한글 폴더 배정 실시.
2. **200장 단위 청크 최적화**: VRAM 파훼를 막기 위해 OOM 방어 지향 Batch 스크립트로 동작.

## ✅ 6단계: 사용자 참여형 AI 피드백 및 자가 학습 시스템 (완료)
1. **오답 정정 즉각 패치**: 모달 상에서 피드백 텍스트 입력 시, 메인 인물 얼굴을 재 스캔하여 학습 배열(`known_faces.pkl`)에 즉각 주입.
2. **로컬 태그 실시간 수정**: 전체 리스캔 없이 해당 사진의 Qdrant Payload 만을 핀셋 조준하여 변경.
