# GumaShop 제작 기준

상위 TheGumaLab 지침과 함께 적용한다.

- 항상 실제 상품이 화면의 주인공이다. 가족, 공간, 판타지 효과가 제품을 가리거나 다른 디저트로 보이게 만들지 않는다.
- 콘티 생성 전에 실제 상품의 공식 사진 또는 검증 가능한 실물 자료를 확인하고 출처를 저장한다. 외형, 코팅 색, 표면 장식, 단면의 층과 비율을 기준으로 고정한다.
- 실제 제품에 없는 과일 토핑, 케이크 장식, 과도한 크림, 다른 색의 코팅을 임의로 추가하지 않는다. 재료 소품은 제품과 구분한다.
- 컷 간 제품의 물리적 크기는 고정한다. 같은 기준 이미지, 받침과 캐릭터의 크기 관계로 비교한다. 카메라 확대와 물리적 크기 변화를 구분한다.
- 스케일 유지는 제품이 화면에서 차지하는 픽셀 크기나 면적의 고정이 아니다. 원근·카메라 거리·렌즈·구도·클로즈업은 다양하게 사용하되 제품과 같은 깊이에 있는 캐릭터·도구·작업대의 실제 크기 관계를 유지한다. 스케일을 맞추기 위해 승인된 콘티를 반복되는 고정 구도로 바꾸지 않는다.
- 연속 컷을 제품 앞·가족 전원 뒤의 같은 정면 구도로 반복하지 않는다. 엄마 토끼가 주로 쿠킹하며, 필요한 인물만 등장시킨다. 엄마의 행동 클로즈업, 손 탑뷰, 인물 없는 제품 매크로, 측면 샷, 큰아들 돼지의 시식처럼 샷과 카메라를 다양하게 구성하면서 제품이 돋보이게 한다.
- 거대한 제품이 작아지는 설정은 지정된 마지막 변환에서만 허용한다. 변환 전에는 지름·높이·비율·받침 크기가 일정하고, 변환 후에는 실제 상품 크기를 따른다.
- 영상은 대사, 내레이션, TTS 없이 배경음악과 효과음만 사용한다. 행동과 표정으로 이야기를 전달한다.
- 시식 장면은 제품이 코 아래 실제 입술에 닿는 위치와 한입 동작을 시간 순서대로 검수한다. 코·볼 접촉, 입의 위치 이동, 손 바뀜, 제품 순간이동을 허용하지 않는다. 손의 이동을 짧게 하고 한입 후 같은 손으로 제품을 유지한다.
- 기본 결과 공유는 웹 링크와 텍스트만 사용한다. 이미지·영상·검수 프레임을 채팅에 출력하지 않는다. 사용자가 특정 결과에 한해 명시적으로 채팅 표시를 허용한 경우에만 그 범위에서 예외를 적용한다.
- 내장 image_gen은 이미지를 자동 표시할 수 있다. 채팅 표시를 허용받지 않은 작업에서는 호출 전에 이 제약을 해결한다.
