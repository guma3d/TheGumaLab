프로젝트 방향을 `주제 입력 → 학습자료/퀴즈 생성 → HTML 저장/열람` 방식의 웹서비스로 확장했습니다.

## 프로젝트 목적

초등학교 3학년 발표용 가족 활동 자료로, 신기한 파충류 14종에 대한 TV 표시용 가로형 PDF 보고서를 제작했습니다.

## 현재 완료 상태

- 최종 PDF 14개 생성 완료
- 각 PDF는 7페이지 구성
- 화면 비율은 TV에 띄우기 좋은 가로형
- 페이지당 이미지는 1장만 사용하도록 정리
- 텍스트가 이미지를 덮거나 박스 밖으로 나가는 문제를 줄이도록 레이아웃 수정
- 자동 이미지 검색으로 맞지 않던 장면은 직접 고른 고정 이미지로 교체

## 7페이지 구성

1. 파충류 사진과 이름
2. 사는 곳: 세계지도와 기본 설명
3. 서식 지역: 강, 바다, 사막, 바위틈 등 실제 환경 사진
4. 먹이: 먹이에 해당하는 사진과 설명
5. 특징: 해당 파충류의 핵심 특징 사진과 설명
6. 퀴즈
7. 정답과 특이한 점

## 중요한 수정 이력

아래 7종은 특징을 직접 보여주는 이미지가 중요해서 `assets/curated_overrides/`의 고정 이미지를 사용합니다.

- 뿔도마뱀: 눈 주변에서 피를 뿜는 방어 흔적이 보이는 사진
- 바실리스크도마뱀: 물 위를 달릴 때 중요한 발과 발가락 사진
- 아르마딜로도마뱀: 둥글게 만 사진
- 마타마타거북: 물고기를 빨아들이듯 잡기 직전의 실제 영상 프레임
- 가시악마도마뱀: 피부 홈 확대 사진
- 팬케이크거북: 바위틈에 숨은 사진
- 바다뱀: 노처럼 납작한 꼬리 확대 사진

## 폴더 구조

- `tools/`
  - `generate_reptile_pdfs.py`: 기본 보고서 생성 및 공통 이미지/레이아웃 함수
  - `generate_reptile_pdfs_detailed.py`: 최종 7페이지 상세 보고서 생성 스크립트
- `assets/curated_overrides/`
  - 직접 고른 핵심 이미지 7개와 이미지 메모
- `outputs/pdfs/`
  - 최종 PDF 14개
- `outputs/qa/`
  - 전체 QA 차트와 수정 집중 확인 차트
- `reptile_reports/`
  - 지도 데이터 캐시. 재생성 시 이미지 캐시도 이쪽에 만들어집니다.

## 다시 생성하는 방법

새 PC에서 압축을 푼 뒤 아래 명령을 실행하면 됩니다.

```powershell
cd <압축을 푼 경로>\reptile_quiz
python -m pip install -r requirements.txt
python .\tools\generate_reptile_pdfs_detailed.py
```

새로 생성되는 PDF와 QA 이미지는 `reptile_reports_detailed/`에 만들어집니다. 이미 검수된 최종본은 `outputs/pdfs/`에 보관되어 있습니다.

## 실행 환경 메모

- Python 3.x 필요
- 필요 패키지: `Pillow`, `pypdf`
- Windows에서는 기본 한글 폰트인 맑은 고딕을 우선 사용합니다.
- 이미지 검색과 다운로드를 다시 수행할 수 있으므로 네트워크 연결이 있으면 좋습니다.
- 직접 고른 핵심 이미지는 프로젝트에 포함되어 있어 재사용 가능합니다.
