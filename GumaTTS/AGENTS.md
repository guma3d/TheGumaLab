# GumaTTS 작업 지침

- 2026-10-11 사용자 확정: 모든 신규 영상 음성은 GumaTTS를 경유하며 아래 카테고리별 모델·화자 기준을 따른다. Food는 Qwen 1.7B Base의 F1-bright-v2(친근하고 조금 더 경쾌한 합성 여성 기준음성+대본 고정)을 사용한다. Food 외 쇼츠는 기존 F4, Story·롱폼은 기존 M5를 유지한다. 롱폼에서 파생한 쇼츠도 F4로 새로 녹음하며 M5 음성을 그대로 재사용하지 않는다. 더 좋은 대안을 사용자가 채택하기 전까지 유지한다. 기존 음성·영상·과거 제작 기록은 보존하고 새 음성은 새 버전으로 저장한다. 모델 선택 승인은 개별 결과물 검수·YouTube 업로드 승인을 대신하지 않는다.
- 상위 AGENTS.md의 한국어 응답·HomeServer 배포·비밀값 보존 지침을 따른다.
- 모든 영상의 신규 음성은 이 서비스가 생성한다. 제작기는 공통 client.py로 요청하고 원본/작업 ID/해시/실제 모델을 연결한다.
- 자연스러운 한국어 말투와 장시간 청취 품질이 최우선이다. 확정된 VoiceDesign 프로필을 사용하며 다른 모델은 비교 시험용이다. 실제 청취하지 않은 음성을 청취 완료·사용자 승인으로 기록하지 않는다.
- 원본/모델/DB/내부 API 토큰은 storage/models 아래 보관하고 출력·커밋하지 않는다. 웹 SSO와 쓰기 요청 출처 검사를 유지한다.
- GPU 작업은 순차 실행한다. 같은 고정 화자의 연속 작업은 최대 32개 단위로 모델·참조 prompt를 재사용하고 배치 완료·실패 시 프로세스 종료로 GPU를 해제한다. 실패 시 다른 모델·외부 유료 API로 자동 전환하지 않는다.
- 짧은 대사에도 생성 원본과 보정 결과의 음량을 각각 측정한다. 단일 패스 동적 loudnorm 출력에 의존하지 않고 측정 기반 고정 게인을 적용하며 결과 음량·피크를 검증한다. 무음·과도한 감쇠는 작업 실패로 처리한다. 파일 존재·디코딩 성공·해시 일치만으로 음성 품질 통과를 기록하지 않는다.

- 2026-10-11 제작 서비스 통합: 호출자는 GumaDdanjit_app이다. 신규 제작 파일과 지침은 D:\TheGumaLab\GumaDdanjit에 저장한다. 기존 세 서비스의 보관본에서 신규 제작하지 않는다. TTS 서비스·선택 음성 F4/M5·토큰은 유지한다.

- 2026-10-11 Food 음성 안정화: 매 컷 독립 VoiceDesign 생성과 seed 고정은 동일 화자 보장이 아니다. F1-bright-v2 기준 WAV·대본·해시를 보존하고 Base create_voice_clone_prompt/generate_voice_clone로 재사용한다. 컷별 과장된 말투 지시는 제거하고 발화 속도·피치·음량·전환·누락을 비교한다. 같은 참조를 사용해도 실제 청취 품질 승인을 대신하지 않는다. 기존 F4 영상과 원본은 보존하고 수정본은 새 웹 버전으로 저장한다.
