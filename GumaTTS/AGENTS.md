# GumaTTS 작업 지침

- 2026-10-11 사용자 최종 채택: 쇼핑쇼츠(Food·Tech·Living)는 대추야자 v11 방식으로 제작한다. 최초 F4 합성 원본 CUT7에서 고정한 F4-dates-v1 참조 WAV·대본·SHA256을 GumaTTS Qwen 1.7B Base(qwen-clone-1.7b)에 넣어 전체 대사를 한 번에 생성한다. 컷별 독립 생성은 하지 않는다. 발화 경계를 대본과 대조해 영상·자막을 맞추고 최종 음성은 분할 재접합하지 않은 연속 마스터를 사용한다. 피치·배속 변경이나 지원되지 않는 Base style/instruct로 말투를 조정하지 않는다. 원본·새 버전·참조 및 마스터 해시·작업 ID·정렬 근거를 보존한다. 모든 컷의 무음·잘림·발음·음량·BGM 대비와 전 프레임 로고를 검수하고 실제 청취 여부를 별도로 기록한다. 기존 5곡 BGM은 일정한 음량으로 유지하며 교체 작업에서는 기존 선택 곡을 보존한다. Story·롱폼 M5와 이야기쇼츠 F4 정책은 유지한다. 음성 방식 채택을 향후 영상의 자동 업로드·공개 승인으로 간주하지 않는다.
- 상위 AGENTS.md의 한국어 응답·HomeServer 배포·비밀값 보존 지침을 따른다.
- 모든 영상의 신규 음성은 이 서비스가 생성한다. 제작기는 공통 client.py로 요청하고 원본/작업 ID/해시/실제 모델을 연결한다.
- 자연스러운 한국어 말투와 장시간 청취 품질이 최우선이다. [통합 안내](../GumaDdanjit/docs/guide-index.md)의 범위별 모델을 따른다. 쇼핑 F4-dates-v1·Story M5-fixed-v1은 Base 복제이며 컷마다 VoiceDesign으로 새 화자를 만들지 않는다. Sohee는 명시적 채택 전 비교 시험이다. 실제 청취하지 않은 음성을 청취 완료·사용자 승인으로 기록하지 않는다.
- 원본은 storage/<job-id>, DB는 storage/jobs.sqlite3, 모델 캐시는 models/, 서비스 토큰은 storage/service-token 등 실제 Compose 마운트 위치에서 관리한다. 비밀값을 출력하거나 원본·모델·DB·토큰을 커밋하지 않는다. 웹 SSO와 쓰기 요청 출처 검사를 유지한다.
- GPU 작업은 순차 실행한다. 같은 고정 화자의 연속 작업은 최대 32개 단위로 모델·참조 prompt를 재사용하고 배치 완료·실패 시 프로세스 종료로 GPU를 해제한다. 실패 시 다른 모델·외부 유료 API로 자동 전환하지 않는다.
- 짧은 대사에도 생성 원본과 보정 결과의 음량을 각각 측정한다. 단일 패스 동적 loudnorm 출력에 의존하지 않고 측정 기반 고정 게인을 적용하며 결과 음량·피크를 검증한다. 무음·과도한 감쇠는 작업 실패로 처리한다. 파일 존재·디코딩 성공·해시 일치만으로 음성 품질 통과를 기록하지 않는다.

- 2026-10-11 제작 서비스 통합: 호출자는 GumaDdanjit_app이다. 신규 제작 파일과 지침은 D:\TheGumaLab\GumaDdanjit에 저장한다. 기존 세 서비스의 보관본에서 신규 제작하지 않는다. TTS 서비스·선택 음성 F4/M5·토큰은 유지한다.

- 2026-10-12 사용자 채택: Story·롱폼은 선정된 M5 비교 음성의 원본을 M5-fixed-v1로 고정하고 GumaTTS 로컬 Qwen3-TTS 1.7B Base Voice Clone으로 컷별 생성한다. 동일 참조 WAV·대본·SHA256과 화자 prompt를 재사용한다. 컷마다 VoiceDesign으로 화자를 다시 만들지 않는다. 기존 버전 보존, 변경 컷만 재생성, 실제 청취 여부 별도 기록 원칙을 유지한다. 쇼핑·다른 쇼츠 정책에는 적용하지 않는다.
