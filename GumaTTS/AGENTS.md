# GumaTTS 작업 지침

- 2026-10-17 톤 최종 승인: Sohee + sohee-upbeat-v1 고정. 정확한 영문 말투 지시·seed=43·모델 revision·승인 샘플 작업/해시는 GumaTTS/voice-policy.json이 기준이다. 승인 샘플 51af3c5b9e9e491dbcca532dd3b75693의 문장 끝까지 밝고 신나는 톤을 유지한다. 차분한 기본 톤으로 되돌리거나 컷마다 다른 감정 지시를 넣지 않는다. 샘플 승인은 전체 재생성본의 청취·업로드 승인과 구분한다.
- 2026-10-17 사용자 확정: 앞으로 새로 생성하는 모든 내레이션은 한국어 기본 화자 Sohee, Qwen3-TTS 1.7B CustomVoice(qwen-1.7b), language=Korean으로 고정한다. F4 VoiceDesign/복제 및 Zephyr 등 다른 화자로 자동 대체하지 않는다. 쇼핑쇼츠는 전체 대사를 한 번에 생성하고 최종 음성은 분할 재접합 없는 연속 마스터로 사용한다. 피치·배속 변경 없이 발화 경계에 영상·자막을 맞춘다. 사용자가 승인한 밝고 신나는 sohee-upbeat-v1 말투(미소·가벼운 발성·끝음절까지 밝은 에너지)를 그대로 사용하고 모델·화자·한국어 설정·작업 ID·원본·마스터 해시를 보존한다. 모든 컷의 발음·무음·잘림·음량·BGM 대비·로고를 검사하되 실제 청취와 자동 검사를 구분한다. 기존 결과와 과거 승인은 보존하며 이번 샥즈 영상만 새 버전으로 교체한다. 음성 정책은 업로드·공개 승인이 아니다.

- 상위 AGENTS.md의 한국어 응답·HomeServer 배포·비밀값 보존 지침을 따른다.
- 모든 영상의 신규 음성은 이 서비스가 생성한다. 제작기는 공통 client.py로 요청하고 원본/작업 ID/해시/실제 모델을 연결한다.
- 자연스러운 한국어 말투와 장시간 청취 품질이 최우선이다. [통합 안내](../GumaDdanjit/docs/guide-index.md)의 범위별 모델을 따른다. 모든 신규 내레이션은 qwen-1.7b / Sohee이며 컷마다 화자를 다시 설계하지 않는다. Sohee는 2026-10-17 신규 제작 고정 화자다. 실제 청취하지 않은 음성을 청취 완료·사용자 승인으로 기록하지 않는다.
- 원본은 storage/<job-id>, DB는 storage/jobs.sqlite3, 모델 캐시는 models/, 서비스 토큰은 storage/service-token 등 실제 Compose 마운트 위치에서 관리한다. 비밀값을 출력하거나 원본·모델·DB·토큰을 커밋하지 않는다. 웹 SSO와 쓰기 요청 출처 검사를 유지한다.
- GPU 작업은 순차 실행한다. 같은 고정 화자의 연속 작업은 최대 32개 단위로 모델·참조 prompt를 재사용하고 배치 완료·실패 시 프로세스 종료로 GPU를 해제한다. 실패 시 다른 모델·외부 유료 API로 자동 전환하지 않는다.
- 짧은 대사에도 생성 원본과 보정 결과의 음량을 각각 측정한다. 단일 패스 동적 loudnorm 출력에 의존하지 않고 측정 기반 고정 게인을 적용하며 결과 음량·피크를 검증한다. 무음·과도한 감쇠는 작업 실패로 처리한다. 파일 존재·디코딩 성공·해시 일치만으로 음성 품질 통과를 기록하지 않는다.

- 2026-10-11 제작 서비스 통합: 호출자는 GumaDdanjit_app이다. 신규 제작 파일과 지침은 D:\TheGumaLab\GumaDdanjit에 저장한다. 기존 세 서비스의 보관본에서 신규 제작하지 않는다. TTS 서비스·과거 음성 원본·토큰은 유지한다.


- 2026-10-12 사용자 요청 비교 시험: 승진 영상의 첫 31컷을 로컬 1.7B CustomVoice Sohee의 동일한 친근한 진행 지시로 컷별 생성한다. 읽는 속도를 유지한 약 5분 시험 영상은 문제 컷 028이 끝나는 첫 28컷으로 구성하고 나머지 생성 컷도 보관한다. 비교 요청은 project=test로 기록하고 원본·설정·작업 ID·해시·실제 청취 여부를 보존한다. 시험 결과의 명시적 채택 전에는 다른 프로젝트 음성 정책을 바꾸지 않는다. 동일 모델·화자·스타일의 CustomVoice 비교 작업도 최대 32개 순차 배치에서 모델을 재사용한다.

- 2026-10-17 Sohee 음량 보정: 희소한 자음 피크 때문에 정적 게인만으로 평균 음량이 부족하면 최대 8dB 이내의 피크 제한(자동 증폭 끔, attack 5ms/release 50ms, 지연 보상) 후 측정 기반 고정 게인을 적용한다. 원본은 보존하고 전후 LUFS·true peak·보정본 해시를 기록한다. 한도를 넘는 원본·무음·클리핑은 계속 실패 처리하며 속도·피치는 변경하지 않는다.
