# GumaTTS 작업 지침

- 상위 AGENTS.md의 한국어 응답·HomeServer 배포·비밀값 보존 지침을 따른다.
- 모든 영상의 신규 음성은 이 서비스가 생성한다. 제작기는 공통 client.py로 요청하고 원본/작업 ID/해시/실제 모델을 연결한다.
- 자연스러운 한국어 말투와 장시간 청취 품질이 최우선이다. Qwen 1.7B를 품질 우선 시험하며 0.6B는 비교용이다. 실제 청취하지 않은 음성을 청취 완료·사용자 승인으로 기록하지 않는다.
- 기존 Zephyr와 과거 음성·영상은 보존한다. 새 기본 목소리는 사용자 청취 후 확정한다.
- 원본/모델/DB/내부 API 토큰은 storage/models 아래 보관하고 출력·커밋하지 않는다. 웹 SSO와 쓰기 요청 출처 검사를 유지한다.
- GPU 작업은 순차 실행하고 완료 시 해제한다. 실패 시 다른 모델·외부 유료 API로 자동 전환하지 않는다.

- 목소리 선택은 VoiceDesign 남녀 각 5종(M1–M5/F1–F5)을 동일 원고·동일 음량으로 비교한다. 후보 표시와 최종 기본 음성 확정을 구분하며, 설계 설명을 실제 청취 평가로 오인하지 않는다.

- 2026-10-11 사용자가 웹에서 선택한 후보는 남성 M5(솔직한 현실 친구), 여성 F4(생기 있는 이야기꾼)다. 더 현실적인 한국어 모델도 비교하기를 원한다. 후보 선택을 최종 기본 모델 확정으로 간주하지 않는다.
